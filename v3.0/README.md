# Cities Manuscript Engine v3.0

**城市规划领域 Q1 英文论文的端到端研究系统**——以研究宪法为核心的螺旋循环架构。不是写作助手，是研究设计引擎：从模糊兴趣到可发表论文，每一步都在验证和修正你的研究设计。

## v3.0 的核心升级

v1.0 是线性流水线（设计→文献→写作）。v2.0 是螺旋循环——每个阶段都在验证和修正研究设计。v3.0 在螺旋循环之上补齐了两层知识库：

### 期刊特化写作指南 (`journals/`)
基于 150+ 篇 Cities 论文逐句提取的分章节写作指南（摘要/引言/综述/数据/方法/研究区域/结果/讨论/结论），每一条写作判断都配真实论文例句出处，可回库核实。

### 引用忠实度审核协议 (`references/`)
三级引用审核：存在性核验 → 内容忠实度分级（EXACT/SUBSTANTIAL/PARTIAL/OVERSTATEMENT/MISMATCH/UNVERIFIABLE）→ 研究设计质量评估。写作中的每一条引用都能被逐条核查。

### 研究宪法 (constitution.md)
研究项目的"活的大脑"。不是一次填完的模板，而是随研究推进不断更新的状态文件。每次对话从宪法开始，到宪法结束。

### 六个循环入口
不管你从哪个阶段进入——模糊兴趣、已有数据、读了文献、跑出了结果、要写章节、全篇审查——都能回到宪法并进行下一步。

### 战略简报
在写作任何章节前，宪法生成一份战略简报：该写什么、不该写什么、引用谁、为什么。

### 研究设计模式库
6 种可复用的定量城市研究设计模式（暴露-响应、差距-分解、阈值-非线性、分类-对比、处理-对照），每种模式告诉你：什么比较有意义、什么方法匹配、什么陷阱要避开。

### 6 个议题模块
不平等、流动性、环境可持续、城市韧性、住房、健康——每个模块编码了子议题、方法论要点、叙事逻辑和写作词库。

## 与其他 Skill 的配合

本 Skill 是**编排中心**（大脑），在具体执行上桥接到专业 Skill：

| 场景 | 使用 |
|------|------|
| 深度英文润色 | `/nature-polishing` |
| 大规模文献检索 | `/nature-academic-search` |

| Nature 格式引用插入 | `/nature-citation` |

## 安装

把本目录（`v3.0/`）复制为你的 skills 目录下的 `cities-knowledge-graph/` 即可。
首次使用请按 `SETUP.md` 完成两件事：① 初始化 `constitution.md`（填入你自己的研究）；② 配置 Zotero 本地库连接。

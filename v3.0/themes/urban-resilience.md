# Urban Resilience — 城市韧性

城市系统应对冲击（自然灾害/气候极端/经济危机/公共卫生）的吸收、适应和转型能力。

---

## 领域边界

**核心问题**：什么使城市在面对冲击时更脆弱或更有韧性？韧性如何在不同群体和空间中分布？

**与相邻主题的区分**：
- vs 环境：韧性关注"冲击-响应"，环境关注"长期暴露和质量"
- vs 不平等：韧性 × 不平等 = 谁的脆弱性更高？
- vs 治理：韧性关注"制度如何学习和适应"

## 方法论要点

**核心方法**：面板分析(前后对比)、网络分析(级联失效)、综合指标构建、案例比较、定性+定量混合

**趋势**：从工程韧性(单一指标)→社会-生态韧性(系统视角)、从静态评估→动态轨迹

**方法陷阱**：
- 韧性的测度高度依赖指标选择 → 需要论证指标的理论基础
- 单城市韧性研究难以一般化 → 需要多城市比较或借助制度变量
- 幸存者偏差 — 只看到恢复了的人，没看到被替代了的人

---

## 研究对象焦点

**人的维度**：位置与移动(恢复轨迹) > 主观感受(安全感知) > 社会经济属性
**地的维度**：城市设施(关键基础设施) > 自然指标(环境暴露) > 土地利用(土地利用变化)

## 叙事逻辑

```
引言: 冲击频发 → 但我们对[什么使系统恢复/谁被落在后面]了解不足
结果: 冲击的影响(描述) → 恢复的轨迹(时间) → 谁恢复谁没有(异质性)
讨论: 韧性来源(什么因素解释恢复差异) → 制度/规划的教训 → 下一次如何更好
```

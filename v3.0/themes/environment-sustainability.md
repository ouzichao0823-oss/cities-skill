# Environment & Sustainability — 环境可持续

城市自然环境质量、资源消耗、生态系统服务及其社会-空间分布。

---

## 领域边界

**核心问题**：城市环境如何变化？谁受益于环境改善？谁承担环境退化的代价？

**与相邻主题的区分**：
- vs 韧性：可持续关注"长期平衡和公平"，韧性关注"冲击后的恢复能力"
- vs 健康：环境关注"环境质量和暴露"，健康关注"健康结果"
- vs 不平等：环境正义 = 环境 × 不平等的交叉

## 方法论要点

**核心方法**：空间回归(SLM/SEM)、地理加权回归(GWR/MGWR)、暴露评估、生命周期分析(LCA)、InVEST模型

**趋势**：静态暴露 → 动态暴露(手机信令)、物理指标 → 感知体验(街景+问卷)、单一环境 → 多环境压力

**方法陷阱**：
- 暴露的尺度不匹配 — LST是30m-1km，人的实际体感温度更精细
- 忽略人的移动性 — 热暴露不在居住地发生（关键 Gap 方向）
- 绿地供给 ≠ 绿地使用 — 需要手机信令/问卷验证

---

## 研究对象焦点

**人的维度**：生理反应(热/污染暴露) > 主观感受(环境满意度) > 位置与移动(暴露轨迹)
**地的维度**：自然指标(LST/PM2.5/NDVI) > 人因指标(绿视率/天空开阔度) > 土地利用

## 叙事逻辑

```
引言: 环境变化+城市化的双重压力 → 但我们对[动态暴露/分配公平/非线性机制]了解不足
结果: 环境指标的空间格局 → 暴露的群体差异 → 驱动因素(自然 vs 人为)
讨论: 环境正义含义 → 规划干预的优先区 → 避免"绿色绅士化"
```

## 跨主题关联

- **× 不平等**（最核心交叉: 环境正义）: 热暴露、绿地可达性的群体差异

- **× 健康**（结果交叉）: 热/污染 → 健康

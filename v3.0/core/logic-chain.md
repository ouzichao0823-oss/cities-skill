# 逻辑链 (Logic Chain)

城市研究定量论文遵循一条可预测的逻辑链。理解这条链 = 理解如何设计研究 + 如何写论文。

---

## 链式结构

```
研究对象 ──→ 议题归属 ──→ 数据来源 ──→ 方法论 ──→ 研究发现 ──→ 讨论回应
   │              │              │             │            │            │
 "研究谁/什么"  "回答什么问题"  "用什么测度"  "怎么分析"   "发现了什么"  "意味着什么"
```

## 各环节详解

### 1. 研究对象 — 你在研究什么？

从 `modules/objects.md` 中定位。一个好的研究对象陈述是：
> "本研究关注 [特定人群] 的 [特定行为/属性] 在 [特定空间] 中的 [模式/差异/变化]"

示例：
- ❌ "研究城市不平等"（太宽泛）
- ✅ "研究低收入流动人口的日常活动空间隔离"（对象明确）

### 2. 议题归属 — 这属于哪个学术对话？

将研究对象映射到议题（见 `themes/` 目录）。一个对象可以映射到多个议题：
- "低收入流动人口的活动空间隔离" → 不平等议题（隔离子议题）+ 流动性议题（活动空间子议题）

> 交叉议题 = 创新点。但需要在写作中明确**以哪个议题为主线**。

### 3. 数据来源 — 用什么测度研究对象？

每个研究对象都有多种可操作化的数据选择：

| 研究对象 | 可选数据 | 选择考量 |
|---------|--------|--------|
| 人的位置 | 手机信令/GPS/问卷 | 精度 vs 样本量 vs 时间跨度 |
| 人的社会经济属性 | 普查/问卷/手机推断 | 准确性 vs 覆盖率 |
| 设施可达性 | POI/GIS网络/GTFS | 更新频率 vs 空间精度 |
| 热环境 | Landsat/MODIS/气象站 | 空间分辨率 vs 时间分辨率 |

> **数据选择本身是方法论决策**——在 Methods 部分需要论证"为什么用这个数据而不是那个数据"。

### 4. 方法论 — 怎么从数据中提取答案？

方法论不是孤立选择的——它必须与前三环一致：
- 研究对象是个体行为轨迹 → 活动空间分析（不是传统聚合统计）
- 议题是"不平等" → 需要分组比较 + 不平等指标（不是均值报告）
- 数据是手机信令（大N） → ML方法可行（但需要可解释性）

### 5. 研究发现 → 讨论回应

**这是正向链和反向链的交汇点：**

- **正向**：方法在数据上跑出结果 → 按议题框架解读 → 回应研究对象的初始问题
- **反向**（写作时）：讨论部分要确保——
  1. 每个发现都回应了引言中提出的 Gap
  2. 方法的局限是否影响了结论的可推广性
  3. 数据本身的限制是否被诚实讨论
  4. 研究对象的选择（如单个城市）是否限制了外部效度

## 逻辑链用于 Gap 发现

当用户提出一个交叉想法（如"用手机信令研究公园可达性的不平等"），沿链逐环检查：

```
对象(公园+人的位置) → 议题(环境正义) → 数据(手机信令) → 方法(可达性+不平等指标)
                                                                              ↓
                                         🔴 Gap 判断 ← 这四环的特定组合在文献中是否已有？
```

- **已有大量文献的组合** → 不是 Gap，但可以找细分空白（如特定人群/特定城市类型）
- **链中某环独特但其他环常规** → 微小 Gap（如新数据做老问题）
- **多环同时创新** → 大 Gap（但风险高，需要论证可行性）

## 逻辑链用于写作自查

写完初稿后，反向验证每条链：
1. 标题是否包含了逻辑链的核心环（对象+议题+方法）？
2. 摘要的每句话是否对应链中的一环？
3. 引言 → 方法 → 结果 → 讨论，是否在回应同一条链？
4. 讨论是否回到了研究对象（而不是跑题到其他群体）？

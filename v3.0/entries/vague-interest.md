# 入口 A: 我有模糊兴趣 → 可检验的研究问题

## 触发

用户说："我想研究XX"、"我对XX感兴趣"、"不知道能不能做XX"、"XX和YY有关系吗"

## 宪法状态要求

无。这是最常见的"从零开始"入口。

---

## 该入口的逻辑

模糊兴趣 → 概念拆解 → 理论匹配 → 第一次提问 → 逻辑链草稿

```
"我对XX感兴趣" 不是研究问题。
研究问题是: "在什么条件下，XX通过什么机制影响了谁的什么结果？"
```

---

## 核心原则

> **模糊兴趣不是研究问题。** 研究问题是: "在什么条件下，什么机制通过什么因素影响了谁的什么结果？"
> 打磨研究问题的完整框架见 `core/research-question-design.md`（七个检验 + 四步打磨法）。

## 步骤

### 1. 拆解兴趣中的概念

用户说的一个词通常有 3-5 个学术含义。先拆解，让用户选择：

| 用户说 | 可能拆出的维度 | 追问 |
|--------|------------|------|
| "不平等" | 收入/空间/交通/环境/健康/数字/住房 | "你关心的是哪种不平等？" |
| "流动性" | 通勤效率/可达性公平/出行模式/社会流动 | "流动性对你来说是一个交通问题，还是一个社会分层问题？" |
| "韧性" | 工程恢复力/生态吸收力/社会适应力/制度学习力 | "你关心的是系统回到原状，还是系统学会改变？" |
| "绅士化" | 商业升级/人口替代/文化置换/房价挤出 | "你看到的现象是店铺变了，还是人变了？" |
| "可达性" | 物理距离/时间成本/经济成本/感知可达性 | "你想衡量的是客观距离还是人的主观感受？" |

> 每个拆解维度都对应 `themes/` 目录下的不同子议题。先拆解，再匹配。

### 2. 匹配理论透镜

> 加载 `themes/<matched-theme>.md` 获取该议题的叙事逻辑和方法论要点。

追问用户：你为什么关心这个问题？你想讲一个什么故事？

| 用户的叙事直觉 | 可匹配的理论透镜 |
|-------------|--------------|
| "有些人被排斥在外" | 空间正义(Harvey)、剥夺与排斥 |
| "时间不够用" | 时间地理学(Hägerstrand)、时间贫困(Vickery) |
| "距离决定机会" | 空间 mismatch 假说、可达性理论 |
| "这个地方变了" | 绅士化理论、空间生产(Lefebvre) |
| "穷人和富人住的地方不一样" | 居住隔离、空间分异 |
| "政策应该改变什么" | 规划评估、政策 mobility |

### 3. 生成"第一次提问"

帮助用户把兴趣压缩成 1-2 句可追问的问题。不需要完美，但需要可操作：

```
模板:
"[什么现象]在[什么群体/空间]中如何表现？
  [什么因素]通过[什么机制]影响了这个现象？
  这个机制在[什么条件下]更强或更弱？"
```

### 4. 建立逻辑链草稿

对照 `core/logic-chain.md`，定位用户的已知和未知：

```
[?] 研究对象: [已明确/需缩小]
[?] 议题归属: [已匹配/需选择]
[?] 数据来源: [已有/需要建议]
[?] 方法论:    [未定/需要数据-方法匹配]
```

### 5. 识别宪法缺口

如果用户已有数据（"我有手机信令"），跳转到入口 B。
告诉用户：宪法现在已经有了哪些字段，下一轮应该推进什么。

---

## 输出

1. 概念拆解结果 + 用户的倾向选择
2. 推荐的理论透镜 + 为什么
3. 第一次提问 (First Cut RQ)
4. 逻辑链草稿
5. **宪法写入**：种子、核心命题(tentative)、理论透镜(tentative)、逻辑链草稿

## 二、引言

### 实测统计（97 篇）

| 指标 | 数值 |
|------|------|
| 独立文献综述节 | ~30%（70% 融入引言） |
| 标题中位数 | 15.0 词 |
| 冒号标题 | 54% |
| 含地理标签 | 85%+ |
| 摘要词数 | 204 词（中位数），150-250 密集区间占 75% |
| 摘要用 "we" | 39% |
| 摘要含发现语言 | 53% |
| 摘要以政策结尾 | 86% |

### 引言首句：六种实测策略（按频率）

| 策略 | 频率 | 句式骨架 | 实例 |
|------|------|---------|------|
| **概念锚定** | 最高 | `[Concept] has become a key [planning/policy] for [purpose]. In practice, however, [tension].` | "The '15-minute city' has become a key planning concept..." |
| **现象陈述** | 高 | `[Phenomenon] [plays a role / is a challenge / has emerged].` | "Urban poverty and spatial injustice are multidimensional phenomena..." |
| **案例锚定** | 中 | `[City], known as [distinctive feature], has experienced [change].` | "Dongguan, known as the world's factory..." |
| **政策锚定** | 中 | `[Policy/regulation] has [changed/introduced] [something].` | "After decades of deconcentration, New York State has initiated densification..." |
| **矛盾/转折** | 低 | `Although [A], [B persists].` | "Although intercity travel has become increasingly convenient, significant inequalities persist..." |
| **传统共识→新证据** | 低 | `[X] has traditionally been studied through [old], yet [new evidence].` | "Income segregation has traditionally been studied through residential patterns, yet..." |

**绝对禁止**: "With the rapid development of urbanization..." — 97 篇中 0 篇用此。这句会直接触发 desk reject。

### 引言五段模板（Cities 特调）

| 段 | 任务 | Cities 特调规则 |
|----|------|---------------|
| 1 | TENSION | 案例或概念锚定；必须嵌入 ≥1 量化事实；不得在此描述城市地理细节（属 Section 3） |
| 2 | WHY LIT CAN'T | 如有独立 Lit Review 节，≤1 段 + ≤3 篇引用；Gap 陈述必须是"两条线没有交叉"而非"没人做过" |
| 3 | QUESTIONS | 接受显式研究问题（非强制假设）；必须 bold；1-2 个，≤2 个 |
| 4 | APPROACH | 开头 "Using [data], this study..."（97 篇实测 0 篇 "Here we..."）；覆盖所有步骤但不展开；不预设发现 |
| 5 | CONTRIBUTION | "tests whether" / "contributes to understanding" / "demonstrates an approach"；末句必须暗示规划含义（86% 实测） |

### Gap 句式库（97 篇中提取）

```
"Few studies address [X]." — 直接但有效，限于技术性 Gap
"In practice, however, [X] often fails to match [Y]." — 概念-实践落差
"It is however unclear whether [X] also [does Y]." — 一个机制检验另一个
"While [A] has been documented, [B] remains underexplored." — 文献不对称
"Such approaches overlook [key dimension]." — 方法局限型
"Despite [trend/evidence], [gap persists]." — 证据-实践裂隙
```

## 三、文献综述

### 实测特征

- **70%** 融入引言（不设独立节）→ 引言 Move 2 = 文献综述
- **30%** 设独立节 → 名称："Literature review and theoretical framework" / "Theoretical framework" / "Literature review and conceptual framework"
- 如果独立成节：**30-40% 含概念框架图**
- 节末必须 1-2 句总结文献地图上的位置

### 核心原则

- 文献综述的功能是**定位**，不是**罗列**
- 核心竞品 2-3 句深度讨论；支撑引用 1 句
- 用"脉络"组织：文献线 A (3-5 篇) 做 X → 文献线 B (3-5 篇) 做 Y → A 和 B 没有对话 = Gap

### 必须排除的内容

1. 和核心命题无关的文献脉络（如时间预算论文不应包含日周期隔离研究）
2. 属于引言 Move 3 的内容（"本研究引入""本文提出"）
3. 假设性举例（"两个总工时相同的人..."）— 文献综述每句话都要有文献支撑
4. 方法论细节（NMF 数学推导、K-means 算法步骤）— 属于 Methods
5. 引用与表达不一致 — 每处引用必须核实原文（Chatterjee 2020 是综述不是"指标"）

### 引用密度

| 层级 | 数量 | 篇幅分配 |
|------|------|---------|
| 核心竞品 (2-3句/篇) | 5-8 篇 | ~50% |
| 支撑引用 (1句/篇) | 12-20 篇 | ~35% |
| 理论渊源 (1-2句/篇) | 3-5 篇 | ~15% |
| **总计** | **20-35 篇** | — |

- 标注分析单元（网格/街道/社区边界）
- Inset map 显示城市在全国的位置

### 方法选择的论证模式

Cities 不要求方法创新，但**要求方法-问题匹配的论证**。

```
❌ "Following Smith (2020), we use OLS regression."
✅ "We use [method] because it allows us to [handle specific data feature] and [answer specific RQ aspect],
   which [alternative method] cannot because [reason]."
```

### 伦理声明

涉及个人数据必须声明脱敏性质 + 机构批准情况。

## 五、结果

### H3 命名规则

```
❌ 主题标签: "Spatial patterns", "Regression results", "Descriptive statistics"
✅ 发现陈述: "Green space accessibility gaps widen in low-income neighborhoods"
```

### 认知递进

```
H3-1: 描述 — 整体格局什么样？
H3-2: 因素/关联 — 什么和这个格局相关？
H3-3: 异质性 — 对谁/哪里更显著？（Cities 特别看重异质性）
```

### 每个 H3 的内部结构

```
首句: 核心发现（方向+量级+统计检验）
中段: 证据（引用图表 + 量化 + 稳健性）
末句: 过渡（暗示这个发现对讨论的意义——但不要展开）
```

### 图表规范

- 地图：指北针 + 比例尺 + 图例
- 颜色：色盲友好（viridis/cividis 色盘，避免红绿对比）
- 统计显著性：图上标 `* p<0.05, ** p<0.01, *** p<0.001`

## 六、讨论

### 五段结构（Cities 审稿人最苛刻的部分）

**§1 综合发现**（3-4 句）
```
"Together, our results reveal that [mechanism] shapes [outcome] through [pathway],
with [specific group/area] being most/least affected."
```
不要 list，要 weave。

**§2 机制解释**（4-6 句）
回答"为什么"。基于理论推理，不是新数据分析。

**§3 与文献对话**（5-8 句，最密集引用）
三大句式：
- 支持: "Consistent with [Author], we find..., extending to [new context]."
- 挑战: "In contrast to [Author] who found [X] in [context], we observe [Y]. This divergence likely reflects [difference]."
- 填补: "While [Author A] documented [X] and [Author B] showed [Y], the mechanism linking them was unclear. Our results suggest [Z]."

**§4 政策含义**（5-8 句，Cities 特有——比其他期刊更长更具体）
必须回答三个问题：
1. 谁应该行动？（命名**具体行动者**）
2. 做什么？（具体行动，不是 "improve" 或 "strengthen"）
3. 哪个发现支持？（每个建议对应一个结果）

**禁止句式**:
- "The government should pay more attention to..."
- "Relevant policies should be improved"
- "More research is needed"（作为政策建议的结尾）

**允许句式**:
- "Municipal planning agencies should prioritize [X] allocation to [Y], because our results show [finding]."
- "For transit agencies, our findings suggest [operational change], given that [finding]."

**§5 限制**（3-5 句）
每个限制 = 1 个具体问题 + 1 个补救方向（不是 1 个道歉）。

## 七、结论

~60% 的 Cities 论文有独立结论。

```
1. 问题 recap (1句)
2. 核心发现 (1-2句，带量级)
3. 政策含义 (2-4句，比讨论 §4 更简洁但同样具体)
4. 未来方向 (1句，具体)
```

不重复摘要。不引入新引用。

## 九、最常见拒稿原因

1. 缺乏对城市政策的**具体**含义（"so what for cities"）
2. 单城市但未论证分析价值（为什么这个城市是检验机制的合适案例）
3. 方法-问题不匹配
4. 引言 Move 2 和讨论 §3 脱节（引言说的 Gap 和讨论回应的不是同一个）
5. 万能模板句式（从标题到摘要到引言首句）
6. 政策建议空泛（"should improve" 但没有具体行动者+行动）
7. 数据透明度不足

## 十、手把手句式库（从 97 篇 Cities 论文提取）

> 每个句式 = 模板 + 实例。`[ ]` 内为可替换部分。直接套用即可。

### 10.1 引言段 1：建立张力

**句式 1: 概念-实践落差（最高频）**
```
The [concept] has become a key [planning/policy] for [purpose].
In practice, however, [problem/tension].
```
实例: "The '15-minute city' has become a key planning concept for neighborhood renewal. In practice, however, facility supply often fails to match residents' actual needs."

**句式 2: 传统共识→新证据**
```
[Topic] has traditionally been studied through [old lens], yet growing evidence
points to [new manifestation / underexplored dimension].
```
实例: "Income segregation has traditionally been studied through residential patterns, yet growing evidence points to its dynamic manifestation in the everyday mobility of individuals."

**句式 3: 政策锚定→问题**
```
For decades, [policy approach] has pursued [goal] through [means].
Yet [outcome] has not materialized for [group/context], because [missing dimension].
```
实例: "Urban policy in China has been built on a spatial premise: that bringing people closer to amenities will give them access. Yet proximity does not guarantee access, because..."

**句式 4: 现象悖论**
```
Although [trend/improvement A], [problem B] persists / has intensified.
```
实例: "Although intercity travel has become increasingly convenient, significant inequalities in access to cross-city activities persist among different groups."

---

### 10.2 引言段 2：命名 Gap

**句式 1: 文献不对称**
```
While [Literature A] has extensively examined [X], [Literature B's dimension]
remains underexplored / has not been systematically examined.
```

**句式 2: 操作化局限**
```
Across [body of work], [key variable] is operationalized through [single metric],
which cannot capture [configurational / multidimensional aspect].
```

**句式 3: 共同盲点**
```
[Body A] treats [X] as [Y]; [Body B] treats [X] as [Z].
Neither treats [X] as [what it should be].
```

**句式 4: 直接 Gap 陈述**
```
Consequently, whether [mechanism / relationship] holds under [condition]
remains unclear / has not been empirically tested.
```
实例: "Consequently, no study has examined whether individuals classified by their time-budget configuration exhibit systematically different activity-space outcomes."

---

### 10.3 引言段 3：研究问题

```
This study therefore asks [N] questions.
First, does [X] constitute [Y]? That is, [operationalized version]?
Second, if [X] does [Y], what specific [outcomes] does it shape,
and how do these effects manifest in [observable patterns]?
```

---

### 10.4 引言段 4：方法预览

```
To answer these questions, we draw on [data] from [N] [subjects] in [city].
[Subjects] are [analyzed/classified] using [method] on [dimensions].
[Supporting analyses] are [conducted] via [techniques] (refs).
```

**Cities 实测**:
- ✅ "Using [data], this study examines..." (58/97 篇)
- ✅ "We employ [method] to [purpose]..."
- ❌ "Here we..." (0/97 篇用此开头)

---

### 10.5 引言段 5：贡献陈述

```
By addressing these questions, this study contributes to [field] in [N] ways.
First, it tests whether [X] constitutes [Y] independent of [Z].
Second, by combining [methods] within a single design, it demonstrates
an approach that makes [dimension] empirically tractable.
```

---

### 10.6 文献综述：论证推进句式

**脉络组织**:
```
One body of work has established that [finding A] (refs). Another has documented
that [finding B] (refs). What connects them—[your angle]—has not been examined.
```

**逐篇深度讨论（核心竞品）**:
```
[Author] ([year]) found that [specific finding] using [method] in [context].
This established [mechanism/pattern]. However, [limitation: what it did not test /
what context it was limited to / what variable it treated as given].
```

**综合判断**:
```
Together, these studies indicate that [conclusion from lit].
Yet [key gap] has not been addressed, because [methodological / conceptual reason].
```

---

### 10.7 方法：方法-问题匹配论证

```
✅ "We use [method] because it allows us to [handle specific data feature]
   and [answer specific RQ aspect], which [alternative method] cannot
   because [reason]."

❌ "Following Smith (2020), we use OLS regression." — 这不是论证
```

**数据描述标准句式**:
```
[Data] were provided by [source], covering [N] records from [N] users in [city]
during [time period]. [Key variables] were derived from [raw data] using [method].
```

### 10.8 结果：发现陈述句式

**H3 标题**:
```
✅ "Time-budget configuration directly governs travel cost and destination diversity"
❌ "Activity space indicators by group"  — 主题标签，不是发现
```

**首句**:
```
[Group A] [exhibited/demonstrated] [significantly higher/lower] [outcome]
than [Group B] (Cohen's d = [value]).
```

**量化报告**:
```
[Outcome] for [Group A] was [X] standard deviations above the mean,
compared to [Y] for [Group B].
```

**过渡到讨论**:
```
These patterns suggest that [mechanism] may be operating through [pathway],
a possibility examined further in the Discussion.
```

### 10.9 讨论：与文献对话句式

**支持已有发现**:
```
Consistent with [Author] ([year]), we find that [finding].
Our results extend this work by showing that [new context/mechanism].
```

**挑战已有发现**:
```
In contrast to [Author] ([year]), who reported [X] in [context],
we observe [Y]. This divergence likely reflects [institutional / methodological
/ contextual difference].
```

**填补空白**:
```
While [Author A] documented [X] and [Author B] showed [Y], the mechanism
linking them was unclear. Our results suggest [Z] as the connecting pathway.
```

**政策含义**:
```
For [specific actor], our findings suggest [specific action], given that
[specific finding]. The current [policy/standard] assumes [X], but our
results show [Y], indicating that [specific revision] is warranted.
```

**❌ 禁止**:
```
"The government should pay more attention to..." — 没有命名谁
"Relevant policies should be improved" — 没有说怎么改
"This has important implications for urban planning" — 空话
"More research is needed" — 偷懒
```

---

### 10.10 结论

```
This study has shown that [core finding, 1 sentence with direction + magnitude].
[Specific actor] can [specific action] by [specific means], because [finding].
[Boundary / limitation], which future work could address through [direction].
```

### 10.11 通用过渡与衔接

**段落间逻辑推进**:
```
建立张力:  "Yet / However / In practice, however,"
引入证据:  "Recent evidence has documented / A growing body of work has shown"
命名Gap:   "Consequently, / As a result, / What remains unclear is whether"
引入方法:  "To address this gap, / To answer these questions,"
报告发现:  "The results reveal that / We find that / Three findings emerge"
引出含义:  "These findings suggest / This implies that / For policy,"
```

**Cities 高频衔接词（实测频率）**:
```
转折: In practice, however (43%) > Yet (27%) > Despite (18%) > Although (12%)
递进: further (38%) > moreover (5%) > in addition (3%)
因果: Consequently (22%) > As a result (18%) > Therefore (12%)
总结: Together (31%) > Overall (8%)
```

## 十一、投稿前自查

□ 引言第一句不是 "With the rapid development..."
□ 引言含显式问题或假设
□ 数据来源表列出所有数据
□ 研究区域图含指北针+比例尺
□ 每个 H3 标题是发现陈述
□ 讨论 §4 命名了具体行动者+行动
□ 每个限制有一个补救方向
□ 所有引用在 Zotero 中真实存在
□ 参考文献格式统一为 APA 7th

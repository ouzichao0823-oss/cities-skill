# Cities Manuscript Engine

## 一句话简介

**城市研究 Q1 英文论文端到端生产系统**——从实验设计到投稿，将中国城市现象转化为国际学术议题。

## 解决的问题

写一篇能发在 *Cities*、*Urban Studies*、*Journal of Transport Geography* 等 Q1 期刊上的英文论文，真正的瓶颈不是英文写作，而是：

1. **问题定义**：怎么把"深圳城中村商业升级"变成一个国际审稿人认为有理论贡献的问题？
2. **实验设计**：比较什么？怎么排除替代解释？分析单元怎么选？
3. **文献定位**：在 ~852 篇 Q1 论文中，你的论文的唯一定位是什么？
4. **叙事转换**：中国特有的制度（户口、土地财政、城市更新）如何框定为方法论优势而非"特殊性"？
5. **写作一致性**：从标题到结论，是否在回应同一条逻辑链？

这个 Skill 就是为解决这些问题而设计的。

## 核心框架

### 逻辑链

```
研究对象 × 议题 × 数据 × 方法 → 论文
```

定量城市研究论文遵从一条可预测的逻辑链。这个 Skill 沿着这条链**双向工作**：

- **正向**（研究设计）：我有什么对象+数据 → 能做什么议题 → 用什么方法 → 哪里有 Gap
- **反向**（写作检查）：我的结论是否回应了最初的研究问题？方法-结果-讨论是否逻辑一致？

### 模块架构

```
cities-knowledge-graph/      684 lines / 15 files
│
├── 研究前段 ──────────────────────────
│   ├── 实验设计：定义比较、排除替代解释、方法选择
│   └── 文献综述：三层综述法 → 竞品矩阵 → Gap精确陈述
│
├── 研究中段 ──────────────────────────
│   ├── 逻辑链编排（设计+写作双向）
│   ├── 竞品定位（论文在文献中的唯一坐标）
│   ├── 中国叙事→国际议题转换
│   ├── 研究对象分类（人的维度 + 地的维度）
│   └── Zotero 竞品情报库（~852篇Q1论文）
│
├── 议题知识 ──────────────────────────
│   ├── 不平等与空间正义（12个子议题+中国变量+叙事逻辑）
│   └── 流动性与交通（12个子议题+中国变量+叙事逻辑）
│
└── 研究后段（写作）───────────────────
    ├── 章节写作：问题定义→结果解读→讨论对话→结论总结
    ├── 英文润色：中译英转换+中国术语标准化+Nature Cities风格
    └── 桥接其他Skill
```

### 渐进式加载

Skill 不会一次性把所有内容塞入上下文。按照用户当前所处的阶段，只加载需要的文件：

| 用户说 | 加载的文件 | ~行数 |
|-------|----------|------|
| "我想用XX数据研究YY" | SKILL.md + objects.md + experiment-design.md | ~133 |
| "帮我做文献综述" | + literature-review.md + corpus.md | ~251 |
| "帮我看这个发现能怎么解释" | + positioning.md + logic-chain.md | ~340 |
| "帮我写引言" | + section-guide.md + themes/ | ~467 |
| "润色这段英文" | + polish.md + cn-to-intl.md | ~542 |

### 使用方式

直接在 Claude Code 中描述你的需求，Skill 会自动触发。例如：

**研究设计阶段：**
> "我有北京一个月的手机信令数据，想做交通不平等，帮我设计实验"

**文献综述阶段：**
> "帮我检索 Zotero 里所有关于活动空间隔离的论文，和我的研究做对比"

**写作阶段：**
> "帮我写引言，我的研究是用 POI+街景 研究深圳商业绅士化"
> "这段中文摘要帮我转成 Nature Cities 风格的英文"
> "检查我的讨论部分是否回应了引言提出的 Gap"

### 添加新议题

1. 复制 `themes/_template.md` → `themes/your-topic.md`
2. 按模板填写：子议题、Zotero引用、中国变量、叙事逻辑、写作词库
3. 在 `SKILL.md` 路由表中加一行：`"你的议题关键词" → themes/your-topic.md`

## 设计原则

1. **模型已知的不重复**：不教模型什么是 Harvey 的空间正义或什么是 Gini 系数——它已经懂了。Skill 只提供它不可能知道的东西：你的 Zotero 库内容、你的研究偏好、你定义的对象分类学。

2. **上下文高效**：整个 Skill 仅 684 行，15 个文件。每次只加载当前阶段需要的文件，不会一次性撑爆上下文。加 10 个新议题也只需 ~500 行增量。

3. **强制系统思考**：逻辑链是一个 checklist，确保模型在自由推理时不跳过关键步骤——比较类型定义、替代解释排除、竞品定位。

4. **中国叙事→国际议题**：不是翻译中文论文，而是用国际理论语言重新提问。中国的制度特征不是"特殊性"，而是检验普遍机制的理想实验室。

# 实验设计 (Experiment Design)

一旦有了研究问题和数据，实验设计决定你的论文**能不能站住**。

---

## 从逻辑链到实验设计

```
研究对象 × 议题 × 数据 → 实验设计需要回答三个问题：
  1. 比较什么？ (What's the contrast?)
  2. 怎么排除替代解释？ (How to rule out alternatives?)
  3. 结果对谁、在哪里成立？ (External validity boundary?)
```

## 第一步：定义比较

定量研究本质上都是比较。你的比较是什么？

| 比较类型 | 示例 | 需要什么 |
|---------|------|---------|
| **跨群体** | 低收入 vs 高收入的活动空间 | 分组变量（收入/户口/年龄）— 数据里有没有？ |
| **跨空间** | 绅士化社区 vs 未绅士化社区 | 空间分类标准 — 用什么指标定义绅士化？ |
| **跨时间** | 地铁开通前 vs 后 | 面板数据或重复截面 — 时间窗口多长？ |
| **跨情景** | 工作日 vs 周末出行 | 时间标签 — 数据精度够吗？ |
| **自然实验** | 某政策在某市实施 vs 未实施 | 处理组/对照组 — 平行趋势可检验吗？ |

> **选择比较时优先考虑制度变量**：中国的户口、行政级别、政策试点提供了天然的分组——比人为切分更有说服力。

## 第二步：排除替代解释

你的发现可能不是你说的那个原因。审稿人会想：

| 审稿人的质疑 | 你的应对 |
|------------|--------|
| "是不是自选择？" | 讨论中诚实承认，如果可能，做稳健性检验（如限制样本到长期居民） |
| "是不是遗漏变量？" | 控制你能控制的（人口、密度、政策），讨论中列出你不能控制的 |
| "是不是反向因果？" | 如果你的数据有时序，用滞后自变量；如果没有，讨论中标注 |
| "是不是测量误差？" | 报告数据的已知局限，做敏感性分析（不同阈值/定义） |
| "是不是刚好这个城市这样？" | 讨论中明确你的城市有何特殊性，不要声称普遍性 |

> **不需要解决所有内生性问题。** 一篇诚实标注局限的论文 >> 一篇假装没有局限的论文。

## 第三步：确定分析单元和样本

| 决策 | 考量 |
|------|------|
| 空间分析单元 | 网格(多少米？) vs 街道 vs 社区(行政/感知) vs 个体 — 每个选择都影响结论 |
| 时间窗口 | 为什么选这个时间段？（政策变化？数据可得？） |
| 样本筛选 | 排除标准是什么？（如排除游客、排除短停留）——报告样本流失 |
| 异常值处理 | 缩尾(winsorize)还是截尾(trim)？哪个分位数？ |

## 方法选择原则

不要因为"别人都用"而选方法。选方法因为**它适合你的比较类型和数据特征**：

- 你的比较是**空间上的** → 空间回归(SLM/SEM)或 MGWR
- 你的比较是**非线性的** → GBDT/XGBoost + SHAP
- 你的比较是**时间上的** → 面板固定效应/DID/Event Study
- 你的比较是**群体间的** → 分组回归/交互项/多层模型
- 你的比较是**多维的**（群体×空间×时间） → 考虑ML+可解释性

## 实验设计写到 Methods 里

Methods 中不要只说"我们用了什么方法"，要说明**为什么用这个方法**：
- "We use [method] because it allows us to [handle specific data feature or answer specific question]."
- "An alternative would be [other method], but it would not [address our specific need] because [reason]."

---

## 实验设计自查

□ 我的比较是什么？（一句话能说清）  
□ 分组/分类标准是否有文献支撑？（不是拍脑袋）  
□ 替代解释中最危险的是哪个？我是否在讨论中诚实面对了？  
□ 分析单元的选择是否有理由？是否做了敏感性检验？  
□ 方法选择是否和我的比较类型匹配？  
□ 样本筛选标准和流失是否会在 Methods 中报告？

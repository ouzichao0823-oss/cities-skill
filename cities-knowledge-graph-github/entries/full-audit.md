# 入口 F: 全篇一致性审查

## 触发

用户说："帮我检查一下整篇论文"、"看看有没有不一致"、"我写完初稿了"

## 宪法状态要求

宪法各字段应该已经填充。如果宪法还是空的 → 用户可能跳过了前面的步骤，建议回退到入口 A。

---

## 核心原则

写完初稿后最大的风险不是语言不好，而是**论证断裂**——某个章节和核心命题失去了联系。

审查不检查语法（留给 nature-polishing）。审查检查的是：**从标题到结论，每一个章节是否都在回应同一条逻辑链。**

---

## 步骤

### 1. 标题审查

```
当前标题: [填入]

检查:
□ 标题是否包含了逻辑链的核心环（对象 + 议题 + 方法？）
□ 标题是否有"发现的方向"（increase/decrease/widen/narrow）？
□ 长度是否在 8-14 词？超过 14 词 → 精简
□ 标题中的"发现"是否在结果中真的报告了？

反例:
- "A Study on Urban Inequality" → 丢失了对象、发现、范围。这是话题标签，不是论文标题。
- "Using big data to study commuting" → 丢失了贡献。方法的提及应该在议题之后，且必须为发现服务。
```

### 2. 摘要-正文一致性

```
摘要中的每一句 → 对应正文哪个章节？
  
  摘要句1: [*] → [对应: ]
  摘要句2: [*] → [对应: ]
  ...
  
  检查:
  □ 摘要中的发现是否在结果中找到了？
  □ 量级是否一致？（摘要说 23%，结果中也必须是 23%）
  □ 摘要的 Gap 陈述是否和引言 Move 2 一致？
```

### 3. 引言-讨论闭环

```
引言 Move 2 提出的 Gap:
  "*..."

讨论是否回应了这个 Gap:
  □ 讨论 §文献对话 — 是否逐一回应了引言引用的核心竞品？
  □ 讨论 §机制解释 — 是否解释引言提出的"为什么"问题？
  □ 讨论 §贡献 — 是否和引言 Move 3 声明的一致？
  
  引言中出现但讨论中消失的论文: [列出 — 需要加入讨论或从引言删除]
  讨论中出现但引言中未出现的论文: [列出 — 需要加入引言或从讨论删除]
```

### 4. 结果-讨论分离

```
结果中的发现:
  H3-1: [*] → 讨论中对应的解读: [找到/未找到]
  H3-2: [*] → 讨论中对应的解读: [找到/未找到]
  H3-3: [*] → 讨论中对应的解读: [找到/未找到]

检查:
□ 讨论是否在重复结果？（如果是，删除重复 — 讨论只做"why"和"so what"）
□ 结果中是否有"解释"（留给讨论）或"政策建议"（留给结论）？
□ 讨论中是否有超过 20% 的内容在复述结果？
```

### 5. 逻辑链一致性

```
贯穿全篇检查:

研究对象: 标题提到[对象] → 引言聚焦[对象] → 方法分析[对象] → 
          结果报告[对象] → 讨论不扩展到无关对象
          
核心命题: 标题暗示[命题] → 引言铺垫[命题] → 方法设计回应[命题] → 
          结果检验[命题] → 讨论解释[命题] → 结论重申[命题]
          
断裂点记录: [标注任何断裂处]
```

### 6. 宪法验证

```
宪法 §2 核心命题: "*..."

问: 如果删除这篇论文的标题和摘要，读者读完讨论后能否反转出核心命题？
  
  能 → 论文在服务宪法。
  不能 → 讨论没有回到命题。需要重写讨论的 §综合 段落。

宪法 §5 竞品坐标: 
  论文讨论中是否和这些竞品发生了对话？
  是否引入了新的竞品文献但没更新宪法 §5？
```

---

## 输出

1. 断裂点清单（按严重程度排序）
2. 每处断裂的建议修复方案
3. **宪法写入**：宪法修订（如有需要）、循环日志、阶段更新为"修订中"

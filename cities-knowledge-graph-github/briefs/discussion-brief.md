# 讨论战略简报

> 基于宪法生成。讨论不是复述结果。讨论是**把你的发现放回宪法§5的竞品地图中对话**。

---

## 核心任务

让审稿人读完后说："我理解了这些发现对我已知的文献意味着什么，以及这个城市应该为此做什么。"

## 六步结构 + 每步的宪法定制

### §1 综合（1段）

```
任务: 1-2句综合你的主要发现。
不是 list 每个发现，而是把它们编织成一个 coherent 的叙述。

模板: "Together, our results reveal that [core mechanism] shapes [outcome]
through [pathway 1] and [pathway 2], with [group] being disproportionately affected.
These findings [extend/challenge/complicate] the conventional view that [prior consensus]."

基于宪法定制:
  如果核心命题是"双重机制" → 综合段要明确说清两个机制的相对重要性
  如果核心命题是"非线性" → 综合段要突出阈值的存在和意义
  如果核心命题是"新语境" → 综合段要点出制度特征如何调节了已有机制
```

### §2 机制解释（1段）

```
任务: 解释为什么会出现你看到的结果。不是 what（结果已报告），是 why。

模板: "This pattern likely reflects [mechanism].
[Variable X] may [affect outcome] through [pathway],
because [theoretical/logical reasoning — not new data].
This interpretation is supported by [auxiliary evidence in your data]."

基于宪法定制:
  理论透镜 = [某理论] → 用该理论的术语解释机制
  → "Viewed through the lens of [theory], [finding] suggests [theoretical interpretation]."
  
  如果你有机制证据（中介/调节/交互）→ 在这里呈现
  如果你没有直接的机制证据 → 诚实说："While our data cannot directly test [mechanism],
  the pattern is consistent with [interpretation based on theory]."
```

### §3 与文献对话（1段，最密集引用）

```
任务: 逐一回应宪法§5 的竞品论文。支持谁？挑战谁？填补什么？

对于宪法§5 中每一篇核心竞品:

[论文A] → 你的发现 [支持/挑战/延伸] 了它
  支持: "Consistent with [Author], we find [X], extending this finding to [new context/different scale/new dimension]."
  挑战: "In contrast to [Author], who reported [X] in [context], we observe [Y]. This divergence likely stems from [institutional/methodological/contextual difference]."
  填补: "While [Author A] documented [X] and [Author B] showed [Y], the intermediate mechanism was unclear. Our results suggest [Z]."

重要: 不要对每篇论文各说一句。要建立对话:
  "Taken together with [Author A] and [Author B], our findings suggest a
  more nuanced picture: [your synthesis that goes beyond any single paper]."
```

### §4 异质性与边界（1段）

```
任务: 你的发现在什么条件下成立？什么条件下不成立？

模板: "Importantly, [your mechanism] is not uniform.
It is [stronger/weaker/absent] for [subgroup] and in [spatial context].
This heterogeneity suggests that [boundary condition / contextual moderator]."

基于宪法定制:
  如果你的核心命题在特定群体中最显著 → 讨论这个群体为什么"特殊"
  如果某些群体没有你预测的效应 → 不要回避，解释这是你的数据限制还是理论边界
  中国语境提示: 户口、城市行政级别、政策时间差 → 可能是异质性的制度来源
```

### §5 限制（1段）

```
任务: 具体说出你的研究的限制。每个限制配一个方向（不是配一个道歉）。

原则: 不泛泛说"data limitations"。每个限制 = 1个具体问题 + 1个可能的补救方向。

模板:
  "First, [specific limitation — e.g., our sample covers only one city,
  which may limit generalizability]. Future work could [specific direction —
  e.g., replicate this analysis in cities with different industrial structures].
  Second, [limitation]. [Direction]."

常见限制类型（选择真正适用你的）:
  - 外部效度: 单城市/单年 → 多城市/面板可验证
  - 测量误差: 手机信令推断收入 vs 普查收入 → 需要验证研究
  - 因果识别: 横截面关联 vs 因果 → 面板/工具变量/自然实验可处理
  - 选择偏差: 只观察到使用的人 → 需要非用户数据
```

### §6 意义（1段）

```
任务: 命名具体的行动者 + 具体的行动。不要泛泛"government should pay attention"。

模板: "For [specific actors — planners, transit agencies, municipal governments],
our findings suggest that [specific action — not just "improve" but "recalibrate X to Y"].
Specifically, [concrete recommendation grounded in your finding]."

基于宪法定制:
  如果理论透镜是空间正义 → "Planning interventions should prioritize [specific group/area]"
  如果理论透镜是环境正义 → "Environmental planning should target [specific areas/groups]
  based on [your finding about unequal distribution]"
  如果你做的是交通 → 命名 transit agencies / transport planners
  如果你做的是住房 → 命名 housing authorities / municipal planning departments
```

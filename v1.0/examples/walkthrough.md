# 完整演示：从研究直觉到研究方案

以下演示 Skill 的完整工作流。

---

## 用户输入

> "我有北京一个月的手机信令数据，想做交通不平等的研究，但不确定具体怎么做。"

---

## Skill 执行过程

### Phase 1: 逻辑链定位

沿链定位用户的已知和未知：

```
[✓] 研究对象: 人的位置(手机信令) + 交通设施(隐含)
[?] 议题归属: "交通不平等" → themes/inequality.md #4 或 themes/mobility.md #跨主题
[✓] 数据来源: 手机信令(一个月, 北京)
[?] 方法论: 未定
[?] Gap: 未定
```

### Phase 2: 概念拆解

"交通不平等" 可以拆解为：
- 可达性不平等（哪些群体的工作/服务可达性更低？）
- 出行成本不平等（哪些群体通勤时间更长/花费更高？）
- 模式不平等（哪些群体被限制在更差的出行方式中？）
- 时间不平等（哪些群体因出行牺牲了更多其他时间？）

### Phase 3: 数据-方法匹配

手机信令数据(一个月) → 能力边界：
- ✅ 可计算：个体活动空间、停留点、OD流、出行距离/时间
- ✅ 可推断：居住地、工作地、收入水平(Lu et al. 2021方法)
- ❌ 不可得：主观感受、出行目的（需要推断）
- ⚠️ 不确定：是否能区分交通模式（取决于数据精度）

推荐方法组合：
1. 活动空间分析 → 量化不同收入组的出行范围差异
2. 可达性计算 → 工作/服务设施的群体差异
3. 基尼/泰尔分解 → 量化不平等的大小和来源
4. 可选：SHAP → 如果加入建成环境变量

### Phase 4: Gap 验证

搜索 Zotero 库 + 在线文献 → 发现：
- 已有研究：大量手机信令×交通公平的研究（C4, C52, C66等）
- 但多数是横截面分析（一周数据）
- 一个月的手机数据 → 可以捕捉**出行行为的周间变异和稳定性**
- **Gap 方向**：交通不平等的**时间维度**——不平等是稳定的还是随时间波动？波动受什么影响（天气/政策/节假日）？

---

## Skill 输出

```markdown
## 研究方案：北京交通不平等的时间维度

### 逻辑链
研究对象: 北京市居民的日常出行行为
议题归属: 交通公平(Transport Equity) — 不平等议题#4 × 流动性议题#2
数据来源: 手机信令(1个月, 北京)
方法论: 活动空间分析 + 面板不平等分解 + 时间序列

### 核心 RQ
"交通不平等在时间维度上是稳定的还是波动的？
 周间变异受什么因素影响？不同群体对波动的敏感性是否不同？"

### 创新点
现有交通公平研究几乎都是横截面快照。
一个月数据可以捕捉出行行为的周间变异，
从而揭示"哪些群体的出行机会更脆弱、更容易受外部冲击"。

### 方法论
1. 活动空间指标(每周) → 面板数据(每人4周)
2. 基尼系数/泰尔指数(每周) → 不平等的时间波动
3. 面板回归 → 波动受什么影响？
4. 分组分析 → 低收入/女性/老年群体的出行是否更脆弱？

### 预期贡献
- 理论上：将交通公平从"静态分布"扩展到"动态脆弱性"
- 方法上：面板活动空间分析在交通公平中的应用
- 政策上：识别哪些群体的出行最不稳定，需要针对性干预
```

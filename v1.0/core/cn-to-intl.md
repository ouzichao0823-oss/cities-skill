# 中国叙事 → 国际议题 (CN → Intl Translation)

中国城市研究的许多议题在中文语境中有成熟的讨论传统，但在国际期刊中需要重新框定(framing)，否则会被视为"local case study"而非"theoretical contribution"。

---

## 核心原则

**不是翻译中文论文，而是用国际理论语言重新提问。**

国际审稿人不会关心"某市某区的规划实践"，他们关心的是：
- 这个案例揭示了一个**什么普遍机制**？
- 中国制度环境为这个机制提供了**什么独特的检验条件**？

---

## 常见转换对照

| 中文叙事习惯 | 国际审稿人怎么看 | 如何转换 |
|------------|---------------|--------|
| "以X市为例的Y研究" | 只是案例报告，不是研究 | 先提出理论问题，再说明X市为何是检验这个问题的理想实验室 |
| "结果表明应加强规划管理" | 谁？做什么？为什么是规划部门？ | 命名具体行动者(planners/transit agencies/municipal governments)，说明具体行动 |
| 以政策建议收尾 | 可以，但必须基于发现 | 每一句政策建议必须对应一个具体发现——不能突然跳到宽泛建议 |
| "具有重要的理论和实践意义" | 空话 | 说明你的发现对哪个理论作了什么修正，对哪个具体实践有什么不同做法 |
| 描述制度背景用长段落 | 审稿人可能不熟悉 | 制度背景压缩到 3-5 句，只交代和你的机制直接相关的部分 |
| "在中国语境下..." | 好的信号！但要具体 | 不要只说"在中国"，要说"中国的[户口制度/土地财政/行政考核]导致了[某机制]" |
| 研究结果只说"正相关/负相关" | 不够 | 报告效应量(effect size)："a one-SD increase in X is associated with a Y% change in Z" |

---

## 中国制度变量：劣势变优势

在国际审稿人眼中，中国独特的制度设置不是"噪音"，而是**天然的外生变异来源**：

| 中国制度特征 | 可转化的研究方法论优势 |
|------------|---------------------|
| 户口制度(hukou) | 清晰的制度性社会分层，排除自选择 |
| 行政级别(直辖市/省会/地级市) | 天然的多层级比较框架 |
| 土地财政与出让制度 | 地方政府行为的清晰激励结构 |
| 五年规划与政策试点 | 准实验设计的天然条件(DID/Event Study) |
| 地铁扩张速度世界第一 | 交通基础设施效应的理想研究窗口 |
| 限购/限行政策 | 出行行为的准外生冲击 |
| 城中村(urban villages) | 独特的非正式住房市场，国际比较价值极高 |

> **写作策略**：不要为中国的"特殊性"道歉。把它框定为"a unique institutional setting that allows us to test [mechanism] that would be difficult to isolate elsewhere"。

## 从中文摘要到英文摘要的转换示例

**中文原文风格**：
> "本文以深圳市为例，基于多源数据，采用空间分析方法，研究了城市商业绅士化的空间格局及其影响因素。结果表明，地铁开通、人口结构和政策引导是主要驱动因素。研究对城市规划实践具有参考价值。"

**转换为国际议题**：
> "How does commercial gentrification unfold spatially in rapidly urbanizing cities? Using Shenzhen as a laboratory—where metro expansion, migrant inflow, and urban renewal policies create sharp spatial variation—we combine POI data with street-view imagery to track commercial transformation at the neighborhood level. We find that metro station opening predicts a 23% increase in experiential consumption venues within 800m, but this effect is contingent on pre-existing neighborhood socioeconomic composition. These findings challenge the assumption that transit investment uniformly triggers gentrification, instead revealing a conditional mechanism that depends on local social fabric."

**差异总结**：
- ❌ "采用空间分析方法" → ✅ 说了具体用了什么数据和为什么
- ❌ "结果表明..." → ✅ 报告了具体效应量(23%, 800m)
- ❌ "具有参考价值" → ✅ 说了挑战了什么假设、揭示了什么机制

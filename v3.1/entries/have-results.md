# 入口 D: 我有初步结果 → 反向推导与宪法修正

## 触发

用户说："我跑出了这个结果"、"我发现一个奇怪的现象"、"这个结果怎么解释"、"我的结果和预期不一样"

## 宪法状态要求

至少 §2(核心命题) 为 tentative。否则先走入口 A。

---

## 核心原则

**结果不是用来"报告"的。结果是用来的"对话"的——和你的理论对话、和文献对话、和宪法对话。**

初步结果经常挑战宪法——这不是bug，这是研究过程的正常循环。入口 D 的价值就是让这个循环显性化。

---

## 步骤

### 1. 结果 → 宪法检查

把你的发现对照宪法的核心命题：

```
宪法预测: [你的核心命题预测了___]

实际发现:
  - 和预测一致: [哪些结果支持了命题？]
  - 和预测不一致: [哪些结果挑战了命题？]
  - 预测之外: [有哪些发现你没有预测到？]

不一致的判断:
  [ ] 数据/方法问题（检查你的分析步骤）
  [ ] 命题需要修正（发现揭示了你没想到的机制）
  [ ] 理论假设有问题（你的理论透镜可能不适合这个问题）
```

### 2. 意外发现的处理

意外发现不是失败。意外发现 + 理论解释 = Contribution。

```
发现: [你没有预测到的结果]

可能的解释:
  a) 机制A: [某理论预测的机制] — 如果是，这个发现回应了什么更大问题？
  b) 语境B: [中国制度特征造成的] — 如果是，它在国际比较中意味着什么？
  c) 方法C: [测量/样本/定义造成的] — 如果是，该做什么稳健性检验？
  d) 真正的 Gap: [文献中没人报告的] — 如果是，你的论文贡献变大了

选择最合理的解释 → 更新宪法核心命题
```

### 3. 如果用户从"描述性结果"开始

```
描述性发现: [整体格局、空间分布、时间趋势]

这个发现意味什么？

→ 如果格局和已有文献一致 → 你的贡献不在"what"，而在"why"或"so what"
  → 问：为什么在这个城市也呈现这个格局？这个格局的后果是什么？

→ 如果格局和已有文献不同 → 你的贡献从描述就开始
  → 问：这个城市有什么特殊性导致了不同的格局？

→ 如果呈现一个此前未被量化的现象 → 描述本身就是贡献
  → 问：这个现象的规模和趋势有什么政策含义？
```

### 4. 从结果推导讨论的逻辑

结果的位置在论文链条中是：

```
结果（what）
  ↓
这个结果意味着什么机制在运作？（how/why）→ 讨论 §机制解释
  ↓
这个机制和已有文献的发现一致还是冲突？→ 讨论 §文献对话
  ↓
这个对话修正了什么理论？→ 讨论 §贡献
  ↓
这对城市规划意味着什么？→ 讨论 §政策含义
```

---

## 输出

1. 结果-宪法一致性诊断
2. 意外发现的解释（选最合理的 + 需要验证的）
3. 讨论逻辑链草稿
4. **宪法写入**：核心命题(refined)、逻辑链.方法论(confirmed)、逻辑链.核心发现(tentative→confirmed)

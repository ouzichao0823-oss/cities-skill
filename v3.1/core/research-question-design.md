# 研究问题设计 (Research Question Design)

> 模糊兴趣不是研究问题。好的研究问题在写出来之前就已经决定了论文能发在哪里。

> 核心参考：Peters, M. A. K. (2025). How to develop good research questions. *Nature Human Behaviour*, 9. 
> Peters 认为好的研究问题是"itchy and persistent"——它驱动并捕捉你的热情，反映创新思维。好的问题通常涉及**重新框定一个未回答的问题、挑战先前的假设，或展示过去的方法如何遮蔽了理解**。

---

## Peters 四阶段法：从模糊到锋利

### 阶段 1: 自我批判式头脑风暴 (Self-Critical Brainstorm)

从真诚的好奇心出发。让想法自由流动，不要追求完美。

**具体技巧**：
- 散步时自言自语并录音 → 转写 → 和笔记对话
- 在听报告或读论文时，持续写下问题和批评
- 和非专业人士讨论——训练自己"习惯犯错"

**这个阶段的核心**：产生尽可能多的原始问题，不做筛选。数量比质量重要。

### 阶段 2: 建立上下文和连接 (Building Context and Connections)

深入文献。目标不是罗列，而是建立**显式连接**。

**具体技巧**：
- 用标签系统标注论文：`#connection` 标记文献间的联系，`#primary` 标记核心论文，`#secondary` 标记支撑论文
- 广泛阅读，包括领域外的文献——交叉连接往往诞生最有创造性的问题
- 推荐使用 Obsidian 等工具做思维导图式笔记

**这个阶段的核心**：构建一个互联的知识网络，而不是一个线性的文献列表。

### 阶段 3: 提炼到本质 (Distilling to the Essence)

重读标记为 `#primary` 的论文，带着一个特定目标：

> **"如果他们做了 [X] 而不是 [Y]，会怎样？"**

这个 [X] 可以是不同的分析方法、不同的控制条件、不同的目标人群、不同的数据源。

**这个阶段的核心**：生成大量"替代方案"——不是为了否定别人的研究，而是为了找到尚未被检验的路径。

### 阶段 4: 最终产品 (The Final Product)

在前三个阶段产生的问题池中，根据三个标准选择最终的研究问题：
1. **资源**：你有数据、时间和技能吗？
2. **专长**：你对这个问题的哪个角度最有发言权？
3. **领域状态**：现在回答这个问题的时机成熟吗？

选定问题后，**系统性识别所有可能的替代解释**，并在实验设计中逐个排除。

## Peters 的四陷阱

| 陷阱 | 表现 | 修正 |
|------|------|------|
| **假设要求陷阱** | 认为所有研究问题必须有一个可证伪的假设 | 探索性、描述性、机制性（"X 如何产生 Y？"）或规范性（"为什么 A 而非 B？"）问题同样有价值 |
| **过度依恋陷阱** | 投入太多了舍不得换题 | 沉没成本谬误——如果问题不对，果断抛弃。有时需要回到第一阶段重新来 |
| **"别人做过了！"陷阱** | 发现类似研究就恐慌 | 极少有完全一样的问题——用你的批评技能找到**微小但关键的差异**：技术、替代解释、或现象本身的细微差别 |
| **锤子和钉子陷阱** | 你擅长方法 X，所以所有问题都看起来像 X | 方法服务于问题，不是反过来。"我最擅长的方法真的是回答这个问题的最佳方式，还是仅仅对我来说最容易？" |

## 一个好研究问题的七个检验（快速参考）

### 1. 可否证性 (Falsifiability)

如果结果无论怎样都解释得通，这不是研究问题——是观点。

```
❌ "城市不平等严重吗？" → 回答永远是"看情况"，无法被证伪
✅ "在控制收入后，通勤时长差异是否独立解释活动范围大小？" → 可以得出"是"或"否"
```

**检验**: 你能想象出什么结果会**推翻**你的预期？如果想象不出，问题太模糊。

### 2. 可操作化 (Operationalizability)

你关心的概念在数据中能否被测量？

```
❌ "城市正义" → 无法直接测量
✅ "低收入群体的日常活动空间面积是否小于高收入群体？" → 收入可测量，活动空间可用手机信令计算
```

**检验**: 你的因变量和自变量有没有明确的、被文献验证过的测量方式？

### 3. Gap 驱动 (Gap-Driven)

你的问题填补了什么空白？

| Gap 类型 | 问题形式 |
|---------|--------|
| 单线推进（最主流） | "[主流研究] 已做 A，但忽视了 [具体 B]——B 如何影响 [结果]？"（注意：不说"两条线从未交叉"；真实论文即使跨两条线也只以"忽视 B"单线表述，[DATE] 真实语料核查） |
| 新语境 | "[已有机制] 在 [新制度环境] 中是否仍然成立？" |
| 新数据 | "[已有问题] 能否用 [更精细/更大规模的数据] 得到不同的答案？" |
| 新方法 | "[已有问题] 用 [新方法] 看，是否会揭示不同维度？" |
| 新问题 | "[被忽视的现象] 是否构成了一个需要解释的研究问题？"（风险最高） |

**检验**: 回答这个问题之后，同行知道的比之前多吗？（而不是"对，我们都知道"或"这谁关心？"）

### 4. 范围 (Scope)

```
太宽: "城市不平等如何影响居民生活？" → 一本书都回答不完
太窄: "某市某地铁站 D 口周三下午 3 点的共享单车数量与周边奶茶店营业额的相关性" → 回答了也无人引用
合适: "某城市不同通勤时长群体的活动空间是否存在系统性差异？" → 一篇论文可以回答，且答案有外推价值
```

**检验**: 这个问题能否在一篇 10,000 词论文中回答？答案是否对至少一个其他城市/情境有意义？

### 5. 理论锚定 (Theoretical Grounding)

好问题不是在真空中提出的——它和一个已有的理论对话。

```
❌ "我想看看某城市人的出行模式" → 没有理论，就没有对话对象
✅ "在 Hägerstrand 时间地理学的框架下，通勤时间约束是否塑造低收入群体的活动空间大小？" 
   → 直接与时间地理学的核心概念（能力约束、耦合约束、权威约束）对话
```

**检验**: 你的问题是否能写成 "[理论] predicts that [X], but whether this holds under [Y condition] is unknown"？

### 6. 比较逻辑 (Comparative Logic)

定量研究本质是比较。你的比较是什么？

| 比较类型 | 问题模板 |
|---------|--------|
| 跨群体 | "长通勤者与短通勤者在活动空间上是否不同？" |
| 跨空间 | "同一居住网格内，不同通勤时长群体是否表现出不同空间行为？" |
| 跨情景 | "周末与工作日的空间行为差异在哪个群体中最大？" |
| 跨维度 | "通勤时长对出行范围的影响是否强于对出行频率？" |

**检验**: 你的问题的答案是否隐含了一个"比"字？（A 比 B 更/不如/不同于...）

### 7. "所以呢" 检验 (The "So What" Test)

回答这个问题之后，谁会做什么不同的事？

```
❌ "描述某城市人的通勤模式" → 然后呢？
✅ "识别时间约束最严重的群体及其空间行为特征，为劳动政策与交通规划的资源优先配置提供依据"
   → 规划部门可以据此调整设施配置，劳动部门可以据此评估周休保护的政策效应
```

**检验**: 如果审稿人在 Discussion 末尾问"so what?"——你的结论段命名了具体的行动者和具体行动吗？

## 从模糊到锋利：问题打磨的四步法

### Step 1: 写出你的初始问题（允许模糊）

```
"我想研究时间与空间的关系。"
```

### Step 2: 界定对象和机制

```
"我想研究 [谁的] [什么时间维度] 如何影响 [什么空间行为]？"
→ "我想研究某城市通勤者的工作日-周末出行安排如何影响他们的非通勤活动空间。"
```

### Step 3: 注入比较逻辑

```
"我想比较 [哪几组] 在 [什么条件下] 的差异？"
→ "我想比较不同通勤时长配置的通勤者，在控制居住地后，活动空间的多个维度是否系统不同。"
```

### Step 4: 锚定理论

```
"这个比较检验了 [哪个理论] 的什么命题？"
→ "检验了时间地理学中能力约束的独立效应——居住地决定锚点位置，但时间约束决定棱柱容积。"
```

### 打磨后的问题

> "在控制居住地的条件下，通勤时长是否构成活动空间分化的独立维度？"

## 常见陷阱

| 陷阱 | 表现 | 修正 |
|------|------|------|
| **描述性陷阱** | "本研究描述了某城市的出行模式" | 加上比较逻辑：谁和谁比？在什么条件下不同？ |
| **数据驱动陷阱** | "我有手机数据，能做什么？" | 先有问题再找数据——不是反过来。有数据→看宪法§4逻辑链哪环可以填 |
| **方法驱动陷阱** | "我可以用 SHAP 分析" | 方法服务于问题。如果 SHAP 不能回答你的 RQ，方法再炫也没用 |
| **太宽泛** | "城市不平等" | 什么不平等？谁和谁之间的？在什么空间尺度上？ |
| **太安全** | 问题答案已经很明显 | 如果你 80% 确定答案——你的 Gap 太小。Gap 应该让人想"真的吗？" |

## 写到宪法里

研究问题打磨完成后，必须反映在宪法中：

```
§1 种子 → 触发你兴趣的那个困惑
§2 核心命题 → 打磨后的一两句话
§3 理论透镜 → 你在和哪个理论对话
§4 逻辑链 → 研究对象/议题/数据/方法是否构成闭环
```

> 如果 §2 不能通过"锋利度检查"（同行会说"我想知道是不是真的"吗？），回到 Step 2 重新打磨。

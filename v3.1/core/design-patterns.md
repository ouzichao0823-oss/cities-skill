# 城市研究设计模式库

定量城市研究的可复用研究设计模式。比理论具体，比方法抽象。每种模式是一套"问题+比较+方法"的配对逻辑。

---

## 为什么需要设计模式

大多数城市研究论文可以归入 6-8 种设计模式。识别你的模式 = 确定你的论证结构 = 确定你需要的证据类型。

---

## 模式1: 暴露-响应 (Exposure-Response)

### 结构
```
设施/环境/政策变化 (暴露源) → 行为/健康/房价/出行 (响应变量)
```

### 核心比较
暴露组 vs 未暴露组（或高暴露 vs 低暴露）

### 常见场景
- 地铁开通 → 周边房价/出行行为变化
- 公园建设/拆除 → 周边居民健康/活动变化
- 污染事件 → 健康/迁移响应
- 商业绅士化 → 周边居民替代

### 方法选项
| 方法 | 适用条件 |
|------|--------|
| DID | 有处理前后数据 + 处理组和对照组 |
| Event Study | 有多个时间点 → 可以检验动态效应和预趋势 |
| RD (断点回归) | 处理分配有明确阈值（如距离地铁800m） |
| 匹配 + DID | 处理组和对照组在可观测变量上差异大 |

### 关键挑战
- **自选择**: 是地铁开通改变了出行，还是想坐地铁的人搬到了地铁站附近？
- **处理异质性**: 同一"暴露"对不同群体的效应不同
- **溢出效应**: 对照组可能也受到了影响(如房价溢出)

### 中国优势
限购/限行政策、地铁扩张速度、政策试点 → 天然的准实验条件

## 模式2: 差距-分解 (Gap-Decomposition)

### 结构
```
测度差距 → 分解来源（群体特征差异 vs 空间结构差异 vs 回报率差异）
```

### 核心比较
群体之间的差距有多大？差距来自哪里？

### 常见场景
- 通勤时间差距：职住分离（空间）vs 交通方式选择（个体）
- 可达性差距：设施分布不均（空间）vs 不同群体住在不同地方（分选）
- 健康差距：环境暴露差异 vs 医疗资源获取差异

### 方法选项
| 方法 | 适用条件 |
|------|--------|
| Oaxaca-Blinder | 线性模型分组分解 |
| 基尼/泰尔分解 | 不平等的来源分解（组间 vs 组内） |
| Shapley分解 | 多因素贡献度（非线性也可） |
| Kitagawa分解 | 率差分解（适用于二分变量） |

### 关键挑战
- 分解的层次取决于分组变量 → 户口 vs 收入 → 结论不同
- 变量之间的相关性 → 一个变量的贡献可能包含了另一个变量的效应

---

## 模式3: 阈值-非线性 (Threshold-Nonlinear)

### 结构
```
连续自变量 → 寻找效应的临界点 → 异质性分析（哪里/对谁更显著）
```

### 核心比较
效应在X的不同取值处是否相同？有没有临界点？

### 常见场景
- 建成环境-出行：密度增加 → 步行增加，但到某个密度后饱和/逆转
- 绅士化-替代：资本进入初期 → 替代加速 → 到某个阶段后减速
- 可达性-房价：到地铁站距离 → 房价衰减 → 非线性

### 方法选项
| 方法 | 适用条件 |
|------|--------|
| GBDT/XGBoost + SHAP | 大N、多变量、不需要预设函数形式 |
| GAM (广义加和模型) | 需要检验显著性 + 置信区间 |
| 分段回归 | 有理论指导的断点位置 |
| MGWR | 空间异质性的非线性效应 |

### 关键挑战
- 阈值是"发现"还是"建模选择"? → 需要理论支撑或交叉验证
- SHAP 不提供显著性检验 → 需要用部分依赖图(PD)和累积局部效应(ALE)补充

## 模式4: 分类-对比 (Typology-Comparison)

### 结构
```
聚类/分类 → 描述各类型特征 → 比较各类型在关键结果上的差异
```

### 核心比较
不同类型之间有何差异？什么因素决定了一个个体/空间属于哪种类型？

### 常见场景
- 活动空间聚类 → 6种加班者类型 (Zheng 2026)
- 出行模式聚类 → 多模式 vs 单模式 vs 无出行
- 绅士化阶段分类 → 早期 vs 中期 vs 晚期
- 社区类型 → 基于建成环境的社区分类

### 方法选项
| 方法 | 适用条件 |
|------|--------|
| K-means | 连续变量、大N、需要提前指定K |
| 潜在类别分析(LCA) | 混合数据类型 |
| 层次聚类 | 不确定K、需要看树状图 |
| 自组织映射(SOM) | 高维数据可视化分类 |

### 关键挑战
- K的选择 → 需要理论和数据双支撑（肘部法则 + 文献依据）
- 分类是手段不是目的 → 分类本身不是贡献，分类揭示的差异才是贡献
- 类型稳定性 → 不同样本/时间段得到不同类型 → 需要验证

## 模式5: 处理-对照 (Treatment-Control)

### 结构
```
政策/事件冲击 → 因果效应识别 → 机制探索
```

### 核心比较
处理组在事件后 - 处理组在事件前 vs 对照组在事件后 - 对照组在事件前

### 常见场景
- 车牌摇号/限行 → 购车行为/出行模式
- 地铁/高铁开通 → 房价/出行/就业可达性
- 行政区划调整 → 公共服务/经济发展
- 城市更新/棚改 → 人口迁移/社区变化

### 方法选项
| 方法 | 适用条件 |
|------|--------|
| DID | 处理组+对照组+前后数据 + 平行趋势可检验 |
| 合成控制法(SCM) | 单个处理单元、多个对照单元 |
| 断点回归(RD) | 处理分配有严格阈值 |
| 工具变量(IV) | 有外生工具（政策/距离/历史） |
| Event Study | 多期面板+需要看动态效应 |

### 关键挑战
- 平行趋势假设 → 必须检验，可以用 event study 框架可视化
- 政策不是随机分配的 → 需要论证为什么你的处理是"准随机"的
- 溢出/一般均衡效应 → 对照组可能也受到间接影响

### 中国优势
五年规划、政策试点、空间断点(行政边界) → 天然因果识别条件

## 如何选择你的模式

```
问自己:
1. 我的核心比较是什么？（跨群体 / 跨时间 / 跨空间 / 跨政策?）
2. 我的数据有没有时间维度？（有 → DID / 没有 → 横截面方法）
3. 我的处理是连续变化还是二元？（连续 → 非线性模式 / 二元 → 处理-对照）
4. 我的贡献是"描述"还是"因果"？（描述 → 差距分解 / 因果 → 处理-对照 / 暴露-响应）
```

> 很多论文混合使用多种模式。如：暴露-响应(主模式) + 阈值-非线性(效应形状) + 差距-分解(谁更受影响)。
> 混合模式的关键：**以哪个为主线？** 你的核心命题决定了主模式。

## 竞争假设法（Competing Hypotheses，蒸馏自 OpenScience hypothesis-generation）

> 任何"发现了 X 效应"的声明，都要先问：**还有哪些别的解释能产生同样的观察？** 系统性列出来、逐一排除，你的因果声明才立得住。这是审稿人攻击"自选择/混杂/替代解释"时的标准防线。

### 五步流程（城市研究适配版）

**第1步：明确待解释的现象。** 用一句话写出你的核心观察/模式。例：*"长通勤者与短通勤者在活动空间上不同。"*

**第2步：文献定位。** 查已有解释（ZotSeek 语义检索 + 竞品坐标§5），明确哪些解释已被排除、哪些没有。

**第3步：生成 3-5 个竞争假设。** 每个都必须是**机制性解释**（能讲出为什么），且彼此可区分。城市研究常见竞争假设来源：
| 竞争来源 | 例 |
|---------|-----|
| 自选择（selection） | 不是通勤时长改变活动空间，而是"想用城市的人"本就选择不同职住 |
| 混杂（confounding） | 通勤时长与收入/住房/职业类别混淆——效应其实是它们的代理 |
| 反向因果 | 不是通勤时间多→活动范围小，而是活动偏好→选择不同居住地 |
| 生态谬误 | 群体层面聚类≠个体层面机制 |
| 测量替代 | 通勤时长指标捕捉的是其他构念（如收入） |

**第4步：按七个质量准则打分。** 对每个竞争假设评估：
- **可检验性** (testability)：能否用现有数据检验？
- **可证伪性** (falsifiability)：什么观察能推翻它？
- **简洁性** (parsimony)：是不是最简解释？
- **解释力** (explanatory power)：能解释多少现象？
- **一致性** (consistency)：与既有理论是否一致？
- **新颖性** (novelty)：是否比现有解释多说了什么？
- **范围** (scope)：覆盖多少观察？

**第5步：设计鉴别性检验（discriminating test）。** 关键：竞争假设必须在**某个可观察量上给出不同预测**。设计检验让它们"打架"，谁预测对谁赢。

### 城市研究落地配方

- **自选择检验** = 嵌套空间控制（同居住地格网内比较）——这是排除"居住分选"竞争假设的鉴别性检验
- **混杂检验** = 控制收入/职业/住房类型后再看通勤时长效应是否存留
- **反向因果检验** = 时间地理学理论论证（时间约束是外生约束）+ 稳健性分析

> **用法**：写 §2 核心命题或 §5 竞品定位时，跑一遍竞争假设法。产出的"鉴别性检验"清单，直接变成你的稳健性分析章节 + 讨论里"alternative explanations"段的素材。
> 链接：宪法 §4 逻辑链（每个链节的置信度=它排除了哪些竞争假设）。

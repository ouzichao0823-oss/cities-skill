## 〇、章节形态的一句话结论（真实语料提炼，无元统计）

- **引言几乎必有独立节**；**讨论常与结论合并**（"Discussion and conclusion"）、**数据常并入方法**——这是 Cities 论文的典型结构，不是遗漏。写稿前先判断你的论文是否需要独立讨论节、独立数据节。
- **摘要普遍含缺口句与带方向的发现句**；含量级数字是少数——但若你的发现带具体量级（如"差异 42%"），写进摘要会显著提升信息密度和审稿人印象。
- **开场 move** 多为 context/gap；**收尾 move** 多为 policy_implication / academic_contribution。
- **两种骨架**：数据驱动实证型（综述融入引言，最常见）vs 政策/治理分析型（独立综述节+框架图）。判断标准：**你的研究是否需要概念框架图来支撑论证**。

## 三、论文整体架构：论证的层层递进

> **核心洞察**：Cities 论文不是七个独立部分的堆叠，而是一条**从"现象到判断"的论证链**。每个章节的功能只有放在整条链中才成立。

```
现象层        引言 Move 1       → 一个城市现象为什么值得关注
              │
问题层        引言 Move 2       → 已有研究知道什么、不知道什么（Gap）
              │
方案层        引言 Move 3       → 我们用什么数据/方法回答
              │
证据层        数据与方法        → 数据来源、研究区域、方法论证
   +          研究区域         （"为什么是这里、为什么这样测"）
   +          结果             → 从描述到机制的发现递进
              │
解释层        讨论             → 发现意味着什么、与文献对话、对城市意味着什么
              │
收束层        结论             → 一句话回答研究问题 + 一个具体行动
```

**章节衔接铁律**（每一对相邻章节的接缝处都必须显式可见）：

| 接缝 | 必须出现什么 |
|------|-------------|
| 引言 → 方法 | 引言 Move 3 承诺的数据/方法，方法节必须逐项兑现 |
| 方法 → 结果 | 结果的组织顺序应呼应方法步骤（方法定义了"先看什么后看什么"） |
| 结果 → 讨论 | 结果的最后一个发现应直接引出讨论的第一个论点 |
| 讨论 → 结论 | 讨论的政策段给出行动者，结论应复用同一个行动者收束 |
| 结论 → 引言 | 结论最终回答的，必须是引言 Move 2 提出的那个 Gap |

## 四、两种典型论文骨架（Cities 实测）

### 骨架 A：数据驱动实证型（手机信令/轨迹/街景，最常见于你的研究类型）

```
1. Introduction            [3-5 段：现象→Gap→数据承诺→发现预告]
2. Data and methods        [2-4 节：数据来源 → 研究区域 → 变量 → 方法]
3. Results                 [3-5 节：描述 → 主发现 → 异质性/机制]
4. Discussion              [2-6 段：综合 → 机制 → 对话 → 政策 → 限制]
5. Conclusion              [1-2 段，常并入 Discussion]
```

### 骨架 B：政策/治理分析型（制度、案例、比较）

```
1. Introduction
2. Theoretical framework / Literature review   [独立成节，含框架图]
3. Data and methods  / Case context
4. Findings / Analysis                        [按主题或案例组织]
5. Discussion / Policy implications
6. Conclusion
```

> 骨架 A 约 70% 把文献综述融入引言；骨架 B 约 30% 设独立综述节。判断标准：**你的研究是否需要概念框架图来支撑论证**。

## 五、全局写作红线（适用于所有章节）

1. **没有"万能模板"开场**。任何章节的第一句都不得是 "With the rapid development of urbanization..." 这类句式。
2. **每个论断要么有引用、要么有数据**。无引用无数据的断言 = desk reject 风险。
3. **每章服务于同一逻辑链**。引言提的 Gap，讨论必须回应；方法承诺的变量，结果必须报告。
4. **写作是具体到抽象**。先给现象/数字，再给概括；不要先抽象后空洞。
5. **字数分配比例**（10,000 词总量下的参考值，以目标期刊实际要求为准）：
   - 引言 ~15-20%、方法 ~25-30%、结果 ~25-30%、讨论 ~20%、结论 ~5%

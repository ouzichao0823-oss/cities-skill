# 完整演示：宪法驱动的螺旋循环

以下是一个完整研究从无到有的 7 轮循环。从模糊兴趣到初稿审查。

---

## 用户设定

一名研究生，有一个模糊的研究兴趣和一份数据，但不知道能做什么。

---

## 第一轮：入口 A（模糊兴趣）

**用户**: "我有北京一个月的手机信令数据，想做交通不平等。但不确定具体怎么做。"

**Skill 动作**:
1. 读取 constitution.md → 空的，没有记载
2. 识别入口 → A（模糊兴趣）
3. 加载 `entries/vague-interest.md` + `themes/inequality.md` + `themes/mobility.md`

**概念拆解**:
"交通不平等" 可以拆为：
- 可达性不平等（谁的工作/服务可达性更低？）
- 出行成本不平等（谁的时间/花费更多？）
- 模式不平等（谁被限制在更差的出行方式中？）
- 时间不平等（谁因出行牺牲了更多其他时间？）

**理论匹配**:
- 时间地理学(Hägerstrand) — 适合"时间"视角的交通不平等
- 交通公平 — 关注分配的正义

**第一次提问**: "交通不平等在时间维度上是稳定的还是波动的？谁的出行更脆弱？"

**宪法写入**:
```
§1 种子: "交通不平等的动态性——是不是有些人不仅出行更差，而且更不稳定？"
§2 核心命题: tentative → "低收入群体的出行机会在时间上更脆弱"
§3 理论透镜: tentative → 时间地理学 + 交通公平
§4 逻辑链: 
  对象: tentative → 北京居民日常出行
  议题: tentative → 交通公平(时间维度)
  数据: confirmed → 手机信令(1个月,北京)
  方法: tentative → 未定
§9 循环日志: [DATE] | 入口A | 确定时间维度为差异化方向 | 下一轮: 入口B(数据能力确认)
```

---

## 第二轮：入口 B（数据能力确认）

**用户**: "一个月的数据够吗？"

**Skill 动作**:
1. 读取宪法 → 已有 tentative 框架
2. 识别入口 → B（有数据）

**数据能力画像**:
```
一个月手机信令 → 
✅ 可计算: 个体活动空间、停留点、OD流、出行距离/时间(每周)
✅ 可推断: 居住地、工作地、收入水平
❌ 不可得: 主观感受、出行目的
⚠️ 不确定: 能否区分交通模式(取决于 ping 频率)
一个月 = 可以捕捉周间变异 → 这是核心差异优势
```

**宪法更新**:
```
§4 逻辑链:
  方法: tentative → 活动空间面板 + 不平等分解(每周)
  
Gap 方向: 一个月数据捕捉"出行行为的周间变异"
→ 现有交通公平研究几乎都是横截面（一周数据）
→ 可以问: 不平等是稳定的还是波动的？
```

## 第三轮：入口 C（竞品定位）

**决定**: 在 Zotero 中搜索竞品

**Skill 动作**:
1. 加载 `corpus/zotero-query.md`
2. 搜索: "transport equity" + "mobile phone data" / "activity space" + "segregation" / "temporal variability" + "mobility"

**竞品分析结果**:
```
已有研究: 大量手机信令×交通公平(按主题检索)
但多数是横截面(一周数据) → 不能捕捉时间波动

最接近的竞品:
- 按主题检索(交通公平+手机信令, 横截面)
- 按主题检索(可达性+手机信令, 静态)
- 按主题检索(活动空间隔离+北京, 横截面)
- Li 2025 TBS(集体活动空间四维指标, 横截面)

Gap: 交通不平等的动态维度——已有研究是"快照"，你是"电影"
Gap 类型: 新组合（时间+交通公平+活动空间）
```

> ⚠️ **[DATE] 真实语料核查**：本例 Gap 句本身是单线推进式（已有研究=快照 → 你=电影，正确写法）；"Gap 类型: 新组合"是**贡献类型标注**（novel synthesis），不是 Gap 句结构。不要把它展开写成"两条文献线相互承认但从未交叉"——真实论文 Gap 句写法详见 `journals/cities/01-introduction.md` 第二节 2.2 小节。

**宪法更新**:
```
§5 竞品坐标:
  Gap 类型: 新组合(时间×交通公平)
  核心竞品: 按主题检索, Li 2025
  
§6 贡献声明:
  理论上: 将交通公平从"静态分布"扩展为"动态脆弱性"
  方法上: 面板活动空间分析在交通公平中的首次应用
```

## 第四轮：入口 A（回到构思——精炼核心命题）

**宪法已成熟到可以精炼核心命题**

**核心命题精炼**:
```
tentative: "低收入群体的出行机会在时间上更脆弱"
    ↓
refined: "交通不平等不仅是'出行少'(空间约束)，也是'出行波动大'(时间脆弱性)。
          低收入群体的日常活动空间在时间上更不稳定，
          且这种不稳定性受外部因素(天气/政策/节假日)的放大效应更强。"
```

---

## 总结：这个演示展示了什么

1. **宪法是活的**。从第一轮的空白到第七轮的完整，宪法逐步完成了所有字段
2. **入口不分先后**。A→B→C→A→E→E→F，循环了 7 次，每次都让宪法更成熟
3. **战略简报锁死方向**。第五、六轮写章节时，简报约束了"该写什么不该写什么"
4. **审查回到宪法**。第七轮的全篇一致性检查，就是问"每个章节是否在服务宪法"

# 研究宪法 (Research Constitution)

> 这是你整个研究项目的 **唯一状态文件**。每次对话的起点和终点都是它。
> 宪法不要求完整——它要求**诚实**。`unknown` 是合法状态，比"假装知道"安全得多。

---

## 宪法状态

```
最后更新: [DATE]  |  阶段: [构思中/文献中/分析中/写作中/修订中]
完成度: [视觉评估]
```

---

## §1 种子 (The Seed)

<!-- 从这里开始。不需要学术化。可以是观察、直觉、困惑、一帧画面。 -->

```
我关心的是:

触发我这个兴趣的原因是:
```

---

## §2 核心命题 (Thesis Statement)

<!-- 整篇论文只为一句话服务。这句话是你的宪法第一条。 -->

```
状态: [空/tentative/refined/confirmed]

[机制 + 方向 + 范围]
```

> **锋利度检查**：这句话能否让同行说"我想知道是不是真的"？
> 如果不能，继续打磨。宪法其他所有字段的存在意义，就是让这句话站住。

---

## §3 理论透镜 (Theoretical Lens)

<!-- 你看这个问题的视角。影响你选什么变量、怎么解读结果、和谁对话。 -->

```
状态: [空/tentative/refined/confirmed]

主透镜: [理论名] — [为什么？这个理论能让审稿人把你的案例视为"检验普遍机制的机会"吗？]
替代透镜: [如果用另一个理论看同样的问题，会有什么不同发现？]

需要解释的关键概念:
- [概念1]: [1句定义 + 在你的语境中怎么操作化]
- [概念2]: ...
```

---

## §4 逻辑链 (Logic Chain)

<!-- 对象 × 议题 × 数据 × 方法 → 发现。每一环标注置信度。 -->

| 链节 | 内容 | 置信度 | 为什么是这个选择？ |
|------|------|--------|-----------------|
| 研究对象 | | [tentative/confirmed] | |
| 议题归属 | | [tentative/confirmed] | |
| 数据来源 | | [tentative/confirmed] | |
| 方法论 | | [tentative/confirmed] | |
| 核心发现 | | [tentative/confirmed] | |

> **tentative** = 本轮可能被挑战或替换。**confirmed** = 经过文献/数据验证，本轮不动。
> 如果你连"为什么是这个选择"都说不清楚，那它就是 tentative。

```
|      |         |         |                                   |
```

## §6 贡献声明 (Contribution)

```
理论上: [修正/扩展/挑战了哪个理论或共识？]
方法上: [这个数据/方法组合为什么是必要的？]
经验上: [在哪个城市/制度/人群中发现了一个什么新事实？]
```

---

## §7 地图 (Atlas)

<!-- 手绘不一定准确，但有地图不会迷路。 -->

```
本研究的核心论证路线:

[问题] → [为什么重要] → [已有谁知道什么] → [但他们不知道___]
    → [我们用___数据+___方法] → [发现___]
    → [这意味着___] → [因此___应该做___]

每一段对应论文章节:
[问题+重要] → 引言 Move 1
[已有+不知道] → 引言 Move 2
[我们用] → 引言 Move 3
[发现] → 结果
[意味着] → 讨论
[因此] → 结论/政策含义
```

## §8 循环日志 (Spiral Log)

<!-- 每次对话后记录：本轮做了什么决定？宪法发生了什么变化？为什么？ -->

```
| 日期 | 入口 | 本轮决定 | 宪法变化 | 下一轮议程 |
|------|------|---------|---------|----------|
|      |      |         |         |           |
```

> 日志不是形式。它是你研究决策的审计追踪。6个月后回来看这栏，你会感谢自己。

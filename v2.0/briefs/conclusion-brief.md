# 结论与标题/摘要战略简报

---

## 结论（如果需要独立写）

> 大多数量化城市研究论文的结论很简短或融入讨论末尾。Nature Cities 仅 4% 有独立结论。

### 如果写结论

```
1. 问题 recap (1句)
2. 核心发现 (1-2句，带量级) — 和宪法§2一致
3. 对城市的意义 (2-3句，命名行动者)
4. 边界/未来方向 (1句，具体)
```

### 不能做的
- ❌ 重复摘要
- ❌ 引入新发现或新引用
- ❌ 笼统的"future research should explore this further"

---

## 标题

> Nature Cities 标题中位数 11 词 / 76 字符。

### 标题公式

```
[研究对象] + [核心发现的方向] + [地理/人口范围]

好的:
- "Commute time gaps between rich and poor widen in Chinese megacities"
- "Income segregation manifests in daily mobility patterns across 12 US cities"
- "Nonlinear effects of density on walking: Evidence from street-view imagery in Shanghai"

不好的:
- "A study of urban inequality" → 丢失了对象、发现、范围
- "Research on commuting behavior using big data" → 丢失了贡献，方法词占位了议题的位置
- "Analysis of the relationship between X and Y" → 没有方向、没有量级
```

### 基于宪法定制

```
标题必须包含:
  - 至少2个逻辑链元素(对象/议题/方法)
  - 发现的方向(不是"Analysis of", 而是"[X] widens/reduces/shapes...")

标题避免:
  - "Analysis of" / "Study on" / "Research on" → 这些都是占位词
  - 把方法放在最前面 → 除非你的贡献是纯方法论
```

---

## 摘要

### 摘要公式（4-5句）

```
1. [问题+重要性] — 宪法§1(种子) + §7(地图)第1句
2. [Gap] — 宪法§5(Gap类型)
3. [方法+数据] — 宪法§4(逻辑链)
4. [核心发现+量级] — 宪法§2(核心命题)
5. [意义] — 宪法§6(贡献声明)
```

### 不能做的
- 摘要中的数字必须和正文完全一致
- 不要出现摘要中没在正文中找到的陈述
- 不要在摘要中引用论文

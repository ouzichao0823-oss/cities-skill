# 结果战略简报

> 基于宪法生成。结果的使命：从描述到机制，每一个 H3 都指向讨论中的一个论点。

---

## 核心任务

结果不是按分析的时间顺序排列，而是按**认知递进**排列：
**描述性发现 → 相关性/因素 → 异质性 → （机制证据，如果有）**

---

## 战略参数（从宪法提取）

```
核心命题: [宪法§2]
理论透镜: [宪法§3 — 影响你如何命名和解读变量]
逻辑链:   [宪法§4 — 特别是方法论环]
```

---

## H3 结构设计

基于核心命题，设计结果小节的秩序：

### 典型结构

| H3 序号 | 发现类型 | 回答什么问题 | 为讨论提供什么 |
|---------|---------|------------|-------------|
| H3-1 | 描述 | 整体格局什么样？ | 基准事实 → 讨论中的"格局意味着什么" |
| H3-2 | 因素/关联 | 什么和这个格局相关？ | 关联 → 讨论中的"为什么相关"（机制解释） |
| H3-3 | 异质性 | 对谁/哪里更显著？ | 群体差异 → 讨论中的"谁应该做什么"（政策含义） |
| H3-4(可选) | 机制 | 为什么相关？ | 因果证据 → 讨论中的理论对话 |

### 基于宪法定制

**如果核心命题的机制是"双重"的**（如：能力约束 + 时间挤压）：
```
H3-1: [整体描述]  
H3-2: [机制1的证据]  
H3-3: [机制2的证据]  
H3-4: [两个机制的相对重要性/交互]  
H3-5: [异质性: 哪个群体受哪个机制影响更大]
```

**如果核心命题的贡献在"非线性"**：
```
H3-1: [整体关联]  
H3-2: [非线性阈值 — SHAP/PD图]  
H3-3: [空间异质性 — MGWR]  
H3-4: [群体异质性 — 分组分析]
```

---

## 每个 H3 的命名规则

❌ 主题标签： "Spatial Patterns"、"Descriptive Statistics"、"Regression Results"
✅ 发现陈述： "Income segregation peaks in inner suburbs"、"Commute time gaps widen with income"

> 审稿人看 H3 标题应该能直接识别你的发现方向。H3 标题 = 核心命题的一个子命题。

---

## 每个 H3 的展开结构

```
首句: 核心发现（方向+量级+统计检验）
  → "We find that [group A] experiences [N%] [more/less] [outcome] than [group B] (p<0.01)."
  
中间: 证据链
  → 引用图/表："Figure X shows the spatial distribution of..."
  → 量化：效应量、置信区间、R²、AIC
  → 稳健性："This pattern is robust to [alternative specification] (Table SX)."
  
末句: 过渡到意义
  → "This pattern suggests [one-step inference — but don't fully explain why yet]."
  → 作用是给讨论留悬念
```

---

## 必须排除的内容

```
❌ 解释 "为什么" → 留给讨论
❌ 政策建议 → 留给结论
❌ 和已有文献的对比 → 留给讨论
❌ "Interestingly..." → 会让审稿人觉得你在讲故事而非报告结果
❌ 在没有统计检验的情况下声称"差异" → 必须有 p 值或效应量
```

---

## 宪法一致性检查

□ 每个 H3 标题是否在为核心命题的某一个子命题服务？
□ 结果中报告的变量名是否和宪法§3(理论透镜)的概念对应？
□ 如果理论预测了方向，结果的方向是否和预测一致？（不一致 → 回入口D）
□ 是否报告了效应量而非只说"显著"？

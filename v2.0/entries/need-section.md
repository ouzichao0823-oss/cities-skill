# 入口 E: 我要写某个章节 → 战略简报 → 执行

## 触发

用户说："帮我写引言/文献综述/方法/结果/讨论/结论/标题/摘要"

## 宪法状态要求

至少 §2(核心命题)、§4(逻辑链)、§5(竞品坐标) 有 tentative 以上的内容。否则应该先回到相应入口。

---

## 核心原则

**模型不应该在没有战略指令的情况下自由写作。** 在动手写任何章节之前，宪法必须生成一份战略简报——告诉模型"这个章节的使命是什么、聚焦什么、排除什么、引用谁"。

---

## 步骤

### 1. 读取宪法 → 确认该章节在论证地图中的位置

对照宪法 §7(地图)，定位该章节的功能：

```
你现在要写: [章节名]

在论证地图中，这个章节的使命是:
  引言   → 建立 stakes + 定义 Gap + 声明贡献
  文献综述 → 不是罗列，是定位。证明你的研究在文献中的唯一坐标
  方法   → 不是描述"用了什么"，是论证"为什么用这个而不是那个"
  结果   → 从描述到机制。每小节的发现指向讨论中的一个论点
  讨论   → 把发现放回文献中对话。支持谁？挑战谁？填补什么？
  结论   → 一句话 recap + 一个行动者命名 + 一个具体行动
```

### 2. 生成战略简报

> 加载对应的 `briefs/<section>-brief.md` 获取该章节的战略模板。

战略简报的格式：

```markdown
## [章节名] 战略简报 — 基于 [宪法核心命题的一行摘要]

### 核心任务
[这个章节在宪法中的唯一使命。一句话。]

### 必须建立的内容
- [要素1: 为什么必须在？和核心命题的关系？]
- [要素2: ...]
- [要素3: ...]

### 必须排除的内容
- [要素X: 为什么不该在这里出现？]
- [要素Y: 会分散读者注意力 / 留给其他章节]

### 引用策略
- 核心竞品(需 2-3 句深度讨论): [从宪法§5 提取 3-5 篇]
  每篇的理由: [为什么这篇是核心竞品而不是背景]
- 支撑引用(1句提及): [N篇，来自 Zotero]
- 理论渊源(经典奠基): [1-3篇]
- 不要引用: [哪些文献不该出现在这个章节？为什么？]

### 与前后章节的连接
- 前接: [上一章节留下什么悬念/问题这个章节要回答？]
- 后启: [这个章节结束时给下一章留什么信号？]

### 宪法一致性检查
- [ ] 这个章节是否在服务核心命题？
- [ ] 标题是否包含逻辑链的关键元素？
- [ ] 讨论是否回到了引言提出的 Gap？
```

### 3. 执行写作

根据战略简报执行写作。

**写作完成后必须执行 SKILL.md 中的自检层**：
- 文献综述 → 自检 A(段落-宪法对照) + B(引用核实) + C(内容筛查)
- 引言 → 自检 A + D(Move 2 篇幅) + E(中英文对照)
- 任何章节 → 自检 A(是否服务核心命题) + F(宪法同步)

### 4. 章节完成后的宪法更新

- 该章节是否让核心命题更锋利了？
- 是否发现了新的竞品文献需要加入宪法§5？
- 是否有意外发现需要回到入口D？

---

## 输出

1. 战略简报（基于宪法 + 章节类型）
2. 写作草稿（由战略简报约束）
3. **宪法写入**：阶段更新、循环日志更新

# 完整演示：宪法驱动的螺旋循环

以下是一个完整研究从无到有的 7 轮循环。从模糊兴趣到初稿审查。

> 案例：一个虚构的"城市绿地可达性与健康"研究——用于演示循环机制。
> 替换为你的议题即可复用同样的流程。

---

## 用户设定

研一学生，有一个模糊的研究兴趣和一份数据，但不知道能做什么。

---

## 第一轮：入口 A（模糊兴趣）

**用户**: "我有关注城市绿地和居民健康的关系。我看到有些社区绿地很多但好像没人用。不确定能做成什么研究。"

**Skill 动作**:
1. 读取 constitution.md → 空的
2. 识别入口 → A（模糊兴趣）
3. 加载 `entries/vague-interest.md` + `themes/environment-sustainability.md` + `themes/health.md`

**概念拆解**:
"绿地-健康" 可以拆为：
- 绿地供给不均（哪些社区绿地更多？）
- 绿地使用不均（谁真的在用？和供给匹配吗？）
- 绿地-健康效应（绿地使用转化为健康效益了吗？）
- 绅士化风险（新增绿地是否挤出了原有居民？）

**理论匹配**:
- 环境正义——关注环境资源的公平分配
- 健康城市——关注建成环境对健康的影响机制

**第一次提问**: "绿地供给和实际使用之间的差距有多大？这个差距在不同社区之间是否系统性地不同？"

**宪法写入**:
```
§1 种子: "绿地建了不一定被用——供给和使用的差距可能有社会-空间规律"
§2 核心命题: tentative → "低收入社区虽然绿地供给不少，但实际使用率更低"
§3 理论透镜: tentative → 环境正义 + 健康城市
§4 逻辑链: 
  对象: tentative → 城市居民绿地使用行为
  议题: tentative → 环境正义(绿地可达性公平)
  数据: confirmed → POI + 土地利用(已有)
  方法: tentative → 未定
§9 循环日志: 2026-07-26 | 入口A | 从供给-使用差距切入 | 下一轮: 入口C(文献)
```

---

## 第二轮：入口 C（竞品定位）

**用户**: "我读了一些绿地可达性的论文，感觉大家都做过了。"

**Skill 动作**:
1. 读取宪法 → 已有 tentative 框架
2. 识别入口 → C（读文献）
3. 加载 `entries/have-literature.md` + Zotero 检索

**竞品分析结果**:
```
已有研究两条脉络:

脉络 A: 绿地供给公平性——用遥感+POI测度绿地的空间分布公平性
  → 成熟。已有大量研究测度"谁住在绿地附近"
  
脉络 B: 绿地健康效应——用问卷+健康数据测度绿地对健康的影响
  → 成熟。已有大量横截面研究

但两条脉络之间有一个空白:
  供给公平 ≠ 使用公平。供给研究假设"有绿地=用绿地"
  但实际使用可能受安全感知、维护质量、社交氛围的影响
  → 用街景数据可以捕捉这些"品质"维度
  → Gap: 绿地品质如何调节"供给→使用→健康"这条链？
```

**宪法更新**:
```
§5 竞品坐标:
  Gap 类型: 新组合(绿地供给公平 × 绿地品质感知 × 实际使用)
  核心竞品: 3-5篇来自Zotero的相关论文
  
§6 贡献声明:
  理论上: 将绿地公平从"数量公平"扩展为"品质+使用公平"
  方法上: 街景+POI融合测度绿地品质
```

---

## 第三轮：入口 A（回到构思——精炼核心命题）

**宪法已成熟到可以精炼核心命题**

```
tentative: "低收入社区绿地使用率更低"
    ↓
refined: "绿地的'可达性公平'不能只看距离。
          街景可测度的品质维度(维护、安全感知)在低收入社区系统性更低，
          导致同等距离下实际使用率更低。
          这意味着'供给公平=使用公平'的假设需要被修正。"
```

---

## 第四轮：入口 E（写引言）

**用户**: "帮我写引言"

**Skill 动作**:
1. 读取宪法 → 所有字段 tentative 以上
2. 加载 `entries/need-section.md` + `briefs/intro-brief.md`
3. 生成战略简报：

```
引言战略简报：

核心任务: 建立"绿地公平需要从数量走向品质+使用"的论证

Move 1 (Stakes):
  从哪里切入: 城市在大力建设绿地 → 但"建了"不等于"用了"
  用什么数字: 引用某城市的绿地覆盖率 vs 实际使用率的差距

Move 2 (Gap):
  供给公平研究成熟 → 但测度的是"距离"，不是"品质"或"使用"
  健康效应研究成熟 → 但没考虑品质如何调节供给→使用的转化
  精确Gap: "While prior work has measured green space equity through
  proximity, whether perceived quality moderates the proximity-use
  relationship remains understudied."

Move 3 (贡献):
  "Here we combine street-view imagery with POI data to measure
  green space quality at scale, testing whether quality explains
  the gap between supply and actual usage across neighborhoods."

引用策略:
  核心竞品(2-3句): 3-5篇 — 供给公平、健康效应、街景方法
  支撑(1句): 8-12篇
```

## 第五轮：入口 E（写讨论）

**用户**: "帮我写讨论"

**Skill 动作**:
1. 加载 `briefs/discussion-brief.md`
2. 生成战略简报

```
讨论战略简报：

§1 综合: "我们的发现揭示，绿地供给公平不等于使用公平——品质维度
  在低收入社区系统性更低，导致同等距离下的使用差距。"

§2 机制: "品质差距可能来自: 维护预算的差异分配、社区居民的
  安全感差异、周边建成环境的步行友好度..."

§3 文献对话:
  → 支持供给公平研究: 距离确实重要，但不是全部
  → 延伸健康效应研究: 品质可能是被遗漏的中介变量
  → 挑战: "proximity = access"的隐含假设需要修正

§4 异质性: "品质效应在低步行友好度的社区中最显著..."

§5 限制: 街景只能测度可见品质(不能测噪音/气味); 使用数据依赖推断

§6 意义: "Municipal parks departments should allocate maintenance
  budgets not just by acreage but by neighborhood need indicators..."
```

**用户**: "我写完初稿了，帮我检查"

2. 逐项审查:

```

摘要-正文一致性:
  ✓ 摘要中每个发现都在结果中找到
  ⚠ 摘要的量级表述需要和结果中完全一致

  ✓ Move 2 的 Gap 在讨论中全部回应
  ✓ 引言的核心竞品在讨论中都有对话

逻辑链一致性:
  ✓ 研究对象、核心命题贯穿全篇未断裂

宪法验证:
  ✓ 读完讨论后可反转出核心命题
  ✓ 所有引用在 Zotero 中验证
```

**宪法写入**: 阶段 → 修订中。修复 1 处不一致后 → 可投稿。

---

## 总结：这个演示展示了什么

1. **宪法是活的**。从第一轮的空白到第六轮的完整，宪法逐步完成了所有字段
2. **入口不分先后**。A→C→A→E→E→F，循环了 6 次，每次都让宪法更成熟
3. **任何城市研究议题都可以复用这套流程**——替换研究对象和议题，循环结构不变
4. **战略简报锁死方向**。写作前生成简报，约束了"该写什么不该写什么"
5. **审查回到宪法**。全篇一致性检查 = 问"每个章节是否在服务宪法"
